# 集成架构

[返回 · 应用架构](../README.md)

本系统第三方与遗留系统集成，明确协议、数据流与防腐边界.

> **集成架构 SSOT**：公司级应用治理框架见 [company/knowledge/application/README.md](../../../../company/knowledge/application/README.md)。

## 集成清单

列出外部系统、用途、对接团队与数据敏感度.

## 集成协议

写 HTTP/消息/文件等选型、认证模式与禁止项.

## 集成数据流

写数据流向、频率、批/实时属性与权威源.

## 防腐层

写 ACL/Adapter 位置、映射规则、错误隔离与重试.
