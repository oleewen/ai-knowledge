# 技术架构

## 技术架构概述

本节概括技术选型、技术雷达与决策记录，为基础设施、中间件与工程实践提供统一基线，并与应用架构、数据架构可对齐。

### 技术选型总览

**应写内容**：按层次或领域归纳主要技术选型（语言、框架、运行时、数据存储、消息等）；每项选型的适用场景与退出条件；与组织技能栈、招聘与培训成本的匹配说明。

**产出建议**：选型总览表（技术 × 用途 × 负责人）；与「禁止/待评估」清单区分。

### 技术栈全景图（Tech Radar）

**应写内容**：采用、试验、评估、暂缓/淘汰的四象限或环状分类；评审周期与准入标准；与业务增长、合规要求变化的关系。避免雷达长期不更新。

**产出建议**：Tech Radar 图或表（可链路至内部 Wiki）；变更记录与评审纪要索引。

### 技术选型决策记录

**应写内容**：重大选型（新引入、替换、下线）的背景、备选方案、决策结论与后果；与 ADR 或技术 RFC 的对应关系。小型选型可聚合记录。

**产出建议**：决策索引表；链路至 ADR/文档；弃用技术的迁移窗口说明。

## 基础设施架构

本节描述计算、网络与边缘交付的落地方式，支撑部署、安全与成本治理。

### 部署架构图（物理 / 云）

**应写内容**：机房、区域、可用区与云账号的拓扑；关键服务部署位置与跨区策略；与数据主权、延迟目标的对应关系。混合云或边缘节点需单独说明。

**产出建议**：部署拓扑图；环境（开发/测试/生产）差异摘要。

### 网络拓扑与安全域划分

**应写内容**：VPC、子网、路由、防火墙边界；DMZ、内网、管理网分层；东西向与南北向流量路径；零信任或传统边界模型的采用范围。

**产出建议**：网络拓扑图；安全域清单及默认拒绝策略说明。

### 云资源规划（VPC / 子网 / 安全组）

**应写内容**：网段与 IP 规划、子网用途、NAT 与出口策略；安全组/NSG 命名与最小权限原则；标签与成本分摊约定。与多租户或隔离策略一致。

**产出建议**：资源规划表或 IaC 模块说明；变更审批与防漂移措施。

### 容器与编排（K8s 集群设计）

**应写内容**：集群划分（业务线/环境/合规域）、节点池与实例类型；命名空间、资源配额与网络策略摘要；Ingress、Service Mesh 或 Gateway 选型。升级与补丁策略。

**产出建议**：集群架构图；关键清单（集群列表、版本、责任人）。

### CDN / 负载均衡 / DNS

**应写内容**：静态与动态加速边界；LB 层（四层/七层）与健康检查；DNS 解析、TTL、灾备切换与健康检查联动。证书与 HTTPS 终止位置。

**产出建议**：流量路径示意图；域名与证书台账索引。

## 中间件与基础组件

本节沉淀共享平台能力选型与使用规范，避免重复建设与安全碎片化。

### 消息队列（Kafka / RabbitMQ / …）

**应写内容**：选型与集群划分；主题/队列命名、分区、保留与压缩策略；与业务事件、顺序、Exactly-once 需求的匹配；运维与监控入口。

**产出建议**：消息平台说明 + 使用规范链接；集群与命名空间清单。

### 缓存（Redis / Memcached）

**应写内容**：部署模式（主从、集群、哨兵）、持久化与淘汰策略；缓存穿透/击穿/雪崩防护；敏感数据是否入缓存及 TTL 约定。

**产出建议**：缓存使用规范；关键实例与容量阈值。

### 搜索引擎（Elasticsearch）

**应写内容**：集群角色、索引生命周期、分片与副本策略；与业务查询 SLA 的匹配；安全与多租户隔离。冷热分层与成本控制。

**产出建议**：集群拓扑摘要；索引命名与模板规范链接。

### 配置中心 / 注册中心

**应写内容**：配置分层（应用/环境/全局）、敏感配置处理、灰度与回滚；服务注册发现协议与健康检查。与特性开关平台的边界。

**产出建议**：平台选型说明；命名空间与权限模型。

### 任务调度平台

**应写内容**：批处理与定时任务的平台选型；任务幂等、失败重试与告警；与业务日历、数据依赖的关系。禁止长事务无监控运行。

**产出建议**：调度平台架构或使用说明；关键任务清单。

### 文件 / 对象存储

**应写内容**：对象存储与块/文件存储的选用场景；桶/容器命名、生命周期与归档；预签名 URL、权限与病毒扫描。合规数据存放区域。

**产出建议**：存储类型对照表；公开与私有读写的策略说明。

## 高可用与容灾

本节定义可用性目标、灾难恢复与韧性工程实践，支撑业务连续性论证。

### 高可用架构设计（多活 / 主备）

**应写内容**：架构模式（同城双活、异地多活、主备等）及适用系统；数据复制方向与一致性级别；单点识别与消除计划。与 CAP 取舍的说明。

**产出建议**：高可用模式示意图；按系统的 RTO/RPO 承诺摘要。

### 容灾方案（RTO / RPO）

**应写内容**：灾难场景清单、恢复目标与演练频率；备份介质、异地复制与恢复流程；与业务、监管要求的对齐。演练记录与改进项。

**产出建议**：容灾矩阵（系统 × RTO/RPO × 演练日期）；Runbook 索引。

### 限流 / 熔断 / 降级策略

**应写内容**：网关、服务、依赖三层的限流维度；熔断条件与半开恢复；降级预案与业务可接受度。与容量、压测结果挂钩。

**产出建议**：策略配置索引或规范；关键接口的保护参数表。

### 故障注入与混沌工程

**应写内容**：实验范围（网络延迟、节点杀、依赖故障）、安全护栏与回滚；与生产变更窗口的关系；实验结论沉淀为改进项。

**产出建议**：实验计划模板或记录；与监控告警的联动说明。

## 性能与扩展性

本节将性能目标、容量与扩展策略显性化，支撑峰值与长期增长规划。

### 性能基线与目标

**应写内容**：核心链路的延迟、吞吐、错误率基线与目标；测量环境与统计口径；与业务 SLA、SLO 的对应关系。

**产出建议**：SLO/性能目标表；与可观测性大盘的指标名对齐。

### 容量规划

**应写内容**：按业务指标（订单量、DAU 等）到资源用量的换算模型；定期评估节奏与预警阈值；成本与预留实例策略摘要。

**产出建议**：容量模型或简表；扩容触发条件。

### 水平 / 垂直扩展策略

**应写内容**：无状态与有状态组件的扩展方式；数据库读写分离、分库分表触发条件；扩展的自动化程度与人工步骤。

**产出建议**：扩展决策树或清单；已知瓶颈与路线图。

### 性能测试方案与报告

**应写内容**：压测场景、数据模型、环境与通过标准；报告归档位置与复测周期；性能回归门禁（与 CI 的关系）。

**产出建议**：压测方案模板；最近报告链接或摘要。

## 安全架构

本节覆盖身份、数据、密钥与合规，与组织安全政策及应用架构中的安全设计一致。

### 认证与授权体系（OAuth2 / OIDC / RBAC / ABAC）

**应写内容**：身份提供者、令牌类型与生命周期；RBAC/ABAC 模型与租户隔离；服务间认证（mTLS、服务账号）。与统一登录、审计的衔接。

**产出建议**：认证授权架构图；角色与权限模型索引。

### 数据加密方案（传输 / 存储）

**应写内容**：TLS 版本与密码套件策略；静态加密（磁盘、列级、应用层）及密钥归属；密钥轮换与兼容性。与数据分级一致。

**产出建议**：加密策略摘要；例外清单与审批。

### 密钥管理

**应写内容**：KMS/HSM 或云密钥服务用法；密钥分级、轮换与访问审计；开发/测试与生产密钥隔离。禁止明文入库与日志打印。

**产出建议**：密钥管理规范链接；关键密钥类型清单。

### 安全审计与日志

**应写内容**：审计事件范围（登录、授权变更、敏感操作）、留存周期与防篡改；与 SIEM 或集中日志的对接。合规举证要求。

**产出建议**：审计字段与保留策略表；查询与告警入口。

### 漏洞管理与安全扫描

**应写内容**：依赖扫描、镜像扫描、DAST/SAST 在流水线中的位置；漏洞分级、SLA 与例外流程；与漏洞赏金或 SRC 的关系。

**产出建议**：扫描工具与频率表；严重漏洞响应流程摘要。

### 等保 / GDPR 合规

**应写内容**：适用的合规框架与控制项映射；技术侧落地（加密、访问控制、数据主体权利的技术支持）；评估周期与证据包位置。

**产出建议**：合规控制与技术措施对照表；免责声明与责任边界。

## 可观测性

本节统一日志、指标、追踪与可视化，支撑排障、容量与 SLO 验证。

### 日志体系（采集 / 存储 / 分析）

**应写内容**：日志级别、结构化字段、Trace ID 注入；采集端（Agent、Sidecar）与存储（冷热分层）；保留与检索成本。敏感信息脱敏。

**产出建议**：日志规范链接；索引与保留策略表。

### 监控告警（指标 / 阈值 / 通知）

**应写内容**：黄金信号与业务指标分层；告警分级、收敛与值班路由；噪声控制与误报处理。SLO  burn rate 或类似策略可选。

**产出建议**：告警规则目录或模板；On-call 与升级链。

### 链路追踪（Tracing）

**应写内容**：采样策略、头部传播规范、与日志指标的关联；后端与前端（如有）的接入方式；存储与成本。

**产出建议**：Tracing 架构图；服务接入清单与采样率说明。

### 大盘与可视化

**应写内容**：系统、业务、SLO 类大盘的划分；所有权与评审；与事故复盘、容量会的使用节奏。

**产出建议**：核心大盘列表及链接；模板或命名规范。

## DevOps 与工程实践

本节描述交付流水线、质量门禁与发布策略，连接开发与运维。

### CI/CD 流水线设计

**应写内容**：构建、测试、安全扫描、制品晋级与环境部署阶段；制品库与不可变部署；与分支策略、环境晋升的对应关系。

**产出建议**：流水线示意图；各阶段工具与失败处理说明。

### 分支管理策略

**应写内容**：主干/GitFlow/Trunk-Based 等选型；分支命名、保护规则与合并要求；与发布节奏、热修复流程的配合。

**产出建议**：分支策略一页说明；与 CODEOWNERS 的衔接。

### 代码规范与审查

**应写内容**：语言级风格、静态检查、提交信息规范；Code Review 最低要求与合并门禁；技术债登记方式。

**产出建议**：规范文档索引；Lint/Format 在 CI 中的强制项。

### 自动化测试策略（单元 / 集成 / E2E）

**应写内容**：各层测试的职责、覆盖率期望与运行频率；测试数据与环境依赖；与流水线阶段的绑定及失败策略。

**产出建议**：测试金字塔或策略表；Flaky 测试治理说明。

### 发布策略（蓝绿 / 金丝雀 / 滚动）

**应写内容**：各环境采用的发布模式；流量切换与健康检查；回滚条件与数据迁移注意事项。与特性开关的配合。

**产出建议**：发布 Runbook 摘要；关键服务发布检查表。

### IaC（基础设施即代码）

**应写内容**：Terraform/Pulumi/CloudFormation 等选型与目录结构；状态存储、锁与权限；审查与计划（plan）门禁。漂移检测。

**产出建议**：IaC 仓库说明；模块与环境映射。

## 开发环境与工具链

本节降低本地与协作门槛，并与生产约束保持一致。

### 本地开发环境搭建指南

**应写内容**：前置依赖（语言版本、容器、云 CLI）、一键脚本或 Compose；与远程开发环境的选项；常见故障与文档维护责任。

**产出建议**：README 或 `docs/dev-setup` 链接；环境校验命令。

### 开发工具清单

**应写内容**：IDE、CLI、API 调试、DB 客户端等推荐与版本；许可证与合规注意事项；可选工具与默认工具区分。

**产出建议**：工具清单表；更新节奏。

### 内部工具 / 平台说明

**应写内容**：内部门户、工单、监控、发布平台等入口与用途；账号申请与权限模型；与外部 SaaS 的边界。

**产出建议**：平台目录（名称 × URL × 负责人）；新人必读链接。
