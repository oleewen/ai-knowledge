# 轻流程用户动作（Agent SSOT）

> **定位**：未绑定意图澄清 / 单元推进环的 docs 技能共用动作字母。  
> **适用**：技能名单见 [workflow-routing.md](workflow-routing.md)（及同类参数确认型技能）。
> **不适用**：语义族（见 [unit-cycle-protocol.md](unit-cycle-protocol.md) 的 `C/M/G/S/F`）；`docs-okf` 无当前单元循环、不强制本字母表（自有 workflow 推进）。  
> **受众**：检查维与默认读者见 [audience-and-language.md](audience-and-language.md)；时机与完成条件见下文。

**最后更新**: 2026-10-23

---

## 动作字母：`C/M/S/F`

| 动作 | 含义 |
| --- | --- |
| **C** | 确认当前单元（或当前参数集），授权执行 / 推进 |
| **M** | 修改参数或范围后重跑本单元 |
| **S** | 跳过当前单元（或后续 phase），不写入 |
| **F** | 在已确认前提下补齐剩余同类单元 |

**无 `G`**。需要加深分析时：改参数后 `M` 重跑，或用户口述再执行下一 phase——不占用字母。

---

## 会话模板（推荐）

```text
即将执行 /<skill>，当前参数如下：
- <关键参数行...>
- 当前单元: <路径或槽位>

C 确认当前单元 / M 修改参数 / S 跳过当前单元 / F 补齐剩余单元
```

各 skill 只替换参数行与「单元」名词（输出目录 / 槽位 / overview / 目标组等），不另造字母。

---

## 边界

宣称当前单元完成前，须已执行本技能写入或脚本步骤（或用户确认的 dry-run），并通过 [受众质检](audience-and-language.md) **A/B**。全过静默；违例须举证并处理完毕，未过不得宣称完成。不新增动作字母，也不引入语义族推进环。

`docs-okf` 在结果摘要交用户前检查 A/B；纯校验 JSON / 退出码可跳过。它按自有 workflow 推进，不强制本字母表。
