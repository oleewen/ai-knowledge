# 受众与语言（Agent SSOT）

> **定位**：跨 skill 的**受众 / 语气 / 信息边界**唯一真源；烤干与轻流程写后质检的公共维。  
> **分工**：烤干能力见 [grilling-skill.md](grilling-skill.md)；推进完成条件见 [unit-cycle-protocol.md](unit-cycle-protocol.md)；轻流程完成条件见 [light-flow-actions.md](light-flow-actions.md)。  
> **本地覆盖**：各 skill `references/audience-and-language.md` 只写**差额**（主读者、宜写/宜弱化、反例、特殊允许区），不复制本文维表。

**最后更新**: 2026-07-29

## 适用范围

| 族 | 技能 | 强制维 | 本地 audience |
| --- | --- | --- | --- |
| `sdx-*` | 全部 | **A/B/C/E**（烤干内） | 必有；统一模板 |

## 公共检查维

| 维 | 名 | 含义 |
| --- | --- | --- |
| **A** | 读者锁定 | 对照技能本地（或轻流程默认表）主读者；正文口吻匹配 |
| **B** | 信息边界 | 宜写有实质；宜弱化不出现在正文（或仅落特殊允许区） |
| **C** | 角色一致 | 文内 Actor/角色与模板、上游、上下文不串戏、不臆造 |
| **E** | 可评审性 | 主读者不查下游文档也能评本对象职责内内容 |

无「用户设定覆盖」维；读者以技能本地声明 / 默认表为准。

---

## 烤干内强制（sdx + 语义族）

进入写后烤干后，**必须**跑 A/B/C/E。未全部通过 → 不得进入 `grilled`，不得写后 `C`。

### 违例分流

| 类型 | 处置 |
| --- | --- |
| **可无损改写**（口吻、术语降级、技术细节挪到允许区且不改承诺） | 非语义 → 自动修订 → 再烤干 |
| **改则动承诺/范围/角色定义** | 语义 → 停问（结论/推荐/数字选项）；确认前不改 |

### 举证

- **全过**：会话**静默**（不强制打印维表）
- **有违例**：必须输出短表后再处置：

```text
受众质检：
- A 读者锁定：违例：<最短证据>
- B 信息边界：通过
- C 角色一致：通过
- E 可评审性：违例：<最短证据>
处置：自动修订 | 语义停问
```

## 轻流程 A/B（含 okf）

1. **时机**：写入或脚本完成后、宣称单元/本轮完成前。`docs-okf`：在结果摘要交用户前；纯校验 JSON/退出码可跳过。
2. **锚点**：下文「轻流程默认读者表」；不建本地 audience。
3. **举证**：同烤干（全过静默；违例才报 A/B）。
4. **门禁**：A/B 未过 → 不得宣称当前单元完成；不新增动作字母。

## 轻流程默认读者表

| 技能 | 主读者 | 宜写 | 宜弱化 |
| --- | --- | --- | --- |
| docs-change | 维护者 / Agent | 变更摘要、路径、基线 | 无关业务长文、臆造原因 |
| docs-pull | 联邦维护者 | 槽位、同步结果、CHANGE-LOG 要点 | 应用内部实现细节 |
| docs-push | 应用库维护者 | 目标 path×doc_dir、复制结果、风险确认 | 中央规约全文粘贴 |
| docs-tag | overview 维护者 | phase 结果、关键词命中摘要 | 无依据扩写业务正文 |
| docs-okf | 工程维护者 | refresh/validate/viz 结论与失败分流 | 把机器日志当知识正文 |
