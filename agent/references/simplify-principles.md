# 精简写作原则（Agent SSOT）

> **定位**：跨 skill 复用的文档**结构 / 简明 / 真源**写作原则唯一真源。就地改写执行见 [docs-simplify/SKILL.md](../skills/docs-simplify/SKILL.md)。  
> **边界**：不负责术语统一 / 定向纠错主路径（→ `docs-revise`）；不负责 A/B/C 判类（→ [document-guidelines.md](../rules/document/document-guidelines.md)）。  
> **分工**：本文只维护写作原则；生成与修订后的调用时机、范围、次数和豁免见 [unit-cycle-protocol.md](unit-cycle-protocol.md)。

**最后更新**: 2026-10-23

## 适用与强制

`/docs-simplify` 按本文改写当前单元；绑定 [单元推进协议](unit-cycle-protocol.md) 的生成与修订按该协议调用本文。轻流程不强制，人类可读正文建议遵守。

原则只维护于此，各 Skill 仅短链，禁止复制整表。结构重组、删冗余与SSOT去重由 `/docs-simplify` 执行；统一术语、链式替换与定向纠错由 `docs-revise` 执行。两者都要且顺序未明确时先确认主目标与顺序，推荐先 revise 再 simplify。

## 模板硬结构

对 **SDD / 示例方案 / 固定章模板**：

1. **保留章骨架与编号实体**；激进精简主攻**叙述散文**与节内套话，不靠拆章「刷短」。  
2. **表密文档行数降幅可有限**——属正常；烤干以可读/可执行/无冗余叙述为准，不以行数 KPI。  
3. 文/节仍做 **A1 结论先行**（可在保留章号下加结论句），不删模板要求的节标题。  
4. 示例内自洽清单（如 §7.4）默认保留；改成「外链模板」须用户确认。

## 三方面原则

### A · 结构（Structured）

| ID | 细则 | 陈述 |
| --- | --- | --- |
| A1 | 结论先行 | 文/节先给结论或行动点（BLUF）；细节下沉 |
| A2 | MECE | 同级要点互斥、合起来覆盖问题；禁交叉复述 |
| A3 | 渐进披露 | 入口短；细节下钻链接，不在入口堆全量 |
| A4 | 结构适切 | 并列→表/列表；流程→编号；禁空壳「概述/说明」标题 |

烤干快检：删掉首段/节首句后是否仍知「要什么」；同级标题能否画成无重叠树。

### B · 简明（Concise）

| ID | 细则 | 陈述 |
| --- | --- | --- |
| B1 | 单意单元 | 一句一意、一段一题；段首句立意 |
| B2 | 极简措辞 | **激进**删套话、同义反复、装饰性举例；**不**为缩短而删必要表行 |
| B3 | 可执行底线 | **约束 / 例外 / 验收条件强制保留**；激进≠删需求真源 |

烤干快检：删装饰后是否仍可执行、可验收。

### C · 真源（SSOT）

| ID | 细则 | 陈述 |
| --- | --- | --- |
| C1 | 单点定义 | 同一事实只一处正文 |
| C2 | 他处引用 | 他处用链接或实体 ID，不复制正文 |
| C3 | 疑似确认 | 全仓语义相似扫到疑似重复时，**须人确认**后再改引用或删段 |
| C4 | 契约面禁改 | 默认不动：实体 ID、YAML frontmatter **契约字段**（如 `id`/`type`/`id`）、已有稳定锚点链接目标、代码块/命令字面量、标明扫描/生成的表列。**允许**：刷新 `updated` / `last_reviewed` 等日期类元数据。用户明示可破其余项 |

烤干快检：同事实是否仍有第二份正文；diff 是否误伤 C4 契约面。
