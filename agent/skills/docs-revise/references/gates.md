# docs-revise 推进绑定

共享契约：[写前澄清](../../../references/intent-clarify.md)、[单元推进](../../../references/unit-cycle-protocol.md)、[写后烤干](../../../references/grilling-skill.md)。本文件只定义本技能的范围与停顿条件。

## 当前单元

一个主文件，或一个已确认的关联/回链修复批次。写入路径逐项列明；动作字母与状态机使用共享契约。

- 写前确认覆盖目标、改动映射、语义边界、文件清单和关联策略。已在当前会话确认的同一单元不重复索要授权。
- 用户改范围、改术语含义或增加写入文件时，更新意图清单并重新确认。
- `S` 与恢复遵循[共享暂停契约](../../../references/unit-cycle-protocol.md#s暂停与恢复)。关联批次暂停不改变已确认主文件的状态；取消扩展须另行明确。

## 检索与写入

| 已知范围 | 可执行动作 | 停顿点 |
| --- | --- | --- |
| 仅本文件 / 禁止关联检索 | 读取、修改和核对该文件 | 发现需外部同步时只报告限制 |
| 允许检索关联候选 | 在约定目录、链深内读候选，判断概念 | 候选写入前确认批次 |
| 已确认关联批次 | 修改清单内文件并核对回链 | 新文件、加深链路或改变语义前 |
| 范围未收口、短词多义、同名路径不明 | 先核实上下文，展示候选与推荐 | 不做未确认的批量替换 |

本技能默认考虑引用链和关键词关联，但这不覆盖用户的范围限制，也不把检索许可变成写入许可。当前单元烤干未收敛，不推进下一批；默认表与操作步骤见 [workflow.md](workflow.md)。

## 需用户决策的变化

术语含义、事实承诺、契约键/ID、标题锚点或关联批次发生变化时，先给结论、推荐和数字选项。范围内非语义修订按共享协议处理。
