# 引用链候选发现

仅在 [gates.md](gates.md) 允许的检索范围内执行。默认从本单元文件检查一层入站和一层出站；新增候选不会自动成为下一层起点。

## 出站（本文件指向谁）

读取 Markdown 链接、引用式链接、反引号路径及注释中的显式文档引用。相对路径按当前文件目录解析，仓库约定的根相对路径按仓根解析；核对目标文件和 `#anchor`。

代码 import 只有在本轮涉及模块引用说明时才作为候选线索，不能据此修改实现逻辑。

## 入站（谁指向本文件）

在获准目录用 `rg -F --` 搜仓根相对路径、可能的后缀路径和文件名；命中后解析链接确认实际目标。同名文件不得仅凭 basename 判定。

排除仓库约定的生成物、构建目录和二进制文件。命中过多时缩小到已知文档目录；仍无法定位则请用户选择范围。

## 同类表述

仅同一术语定义、同一列表项、摘要或复制段属于同步候选。记录「路径 / 同概念证据 / 建议改动 / 保留理由」，不把字面近似视为授权。

## 深度

一层未覆盖时报告遗漏风险。只有用户确认更深范围后才继续；维护已访问集合，避免循环引用无限扩展。无直接链接的表述见 [关键词发现](semantic-keyword-discovery.md)。
