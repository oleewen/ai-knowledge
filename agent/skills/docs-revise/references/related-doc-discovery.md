# 引用链检索

未声明「仅本文件」时，对**本轮已改的每个文件**做入站+出站。默认 **一层入站 + 一层出站**；用户要「全链」再加深并提示风险。  
无语义链接的术语对齐：[semantic-keyword-discovery.md](semantic-keyword-discovery.md)。

## 出站（本文件指向谁）

- **MD/文本**：`[]()`、反引号内 `*.md`、`docs/…` 等；相对路径.resolve 到仓内路径。  
- **代码注释**：显式路径、`@path`、`TODO(file:)`、文档 URL。`import` 等仅在本次影响「如何引用该模块」叙述时再动目标注释，避免无关扰动。

## 入站（谁指向本文件）

对可检索键 `rg -F`（至少）：仓内相对路径、自某目录起的后缀路径、文件名（**同名多文件 → 候选请用户挑**）。

排 `target/`、构建产出、二进制区（与仓库约定一致）。命中过多 → 先试 `docs/`、`{DOC_DIR}/`，否请缩范围。

## 同类表述

与主变更**同一术语定义、同一列表项、同一摘要句、明显复制段**才对齐；勿合并**仅字面相近义不同**的段。

## 深度

默认一层；扩展 BFS 前说明工作量/误伤。完成后若仍有散落，再接关键词检索。
