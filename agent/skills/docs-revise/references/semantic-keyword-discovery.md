# 关键词与语义候选

用户要求统一同类表述、或引用链未覆盖可重复术语时，在已确认的检索范围内补查。用户禁止全库搜索时，不用本流程绕过限制。

先列出可检索路径：仅获准一层关联时，关键词查主文件与已确认的一层候选；用户另行允许目录级检索时，才在该目录搜索。

1. 从用户映射和主文件提取少量高辨识短语，用 `rg -F --` 搜索；先读主文件再检索。
2. 必要时补同义、中英、缩写和大小写变体，逐项读取上下文；短词或高频词先缩范围。
3. 将命中标为同概念候选、异义保留或待确认；候选写入按 [gates.md](gates.md)。

例如正文「订金」与配置键 `deposit`、历史引文中的原词不能因概念相关就一并替换。API/配置键迁移需要独立的变更意图和验证。

候选清单交 [工作流](workflow.md)；生成物、锁文件、构建目录遵循仓库排除约定。
