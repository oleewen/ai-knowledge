## 宜写 / 宜弱化

| 宜写 | 宜弱化 |
| --- | --- |
| 原语境内的准确术语和已核实表述 | 为统一词面引入实现黑话 |
| 改动范围、关联依据和验证限制 | 超范围结构调整与未经核实的承诺 |

## 反例

| 避免 | 推荐 |
| --- | --- |
| 业务说明改成配置键和内部调用术语 | 保持业务读者能理解的表述 |
