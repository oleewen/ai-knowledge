# 易错点

- **明确范围仍反复追问**：复用会话中已确认的单元；变化才重新收口，见 [gates.md](references/gates.md)。
- **同名文件误同步**：解析实际链接目标，再判断入站引用，见 [引用链](references/related-doc-discovery.md)。
- **旧词清零误伤**：历史引文、异义用法、API/配置键可能应保留，见 [关键词](references/semantic-keyword-discovery.md)。
- **只改标题忘回链**：标题文本可能决定 slug，纳入受影响引用检查。
- **评测假通过**：回复提到「仅本文件」不能证明工具未搜全库；核对轨迹与 diff，见 [evaluation.md](references/evaluation.md)。

烤干与 simplify 遍的次数、豁免及停顿只按 [共享推进协议](../../references/unit-cycle-protocol.md)，不在本文件另设规则。
