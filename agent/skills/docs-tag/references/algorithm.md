# 共现候选词算法

候选分数是**命中章节中的词频**，不是语义置信度；最终由用户选词。实现与停用词唯一维护于 [keyword_tag.py](../scripts/keyword_tag.py) 的 `collect_candidates`。

## 扫描与提词

1. 递归读 scan-dir 下 `.md`，按目录和文件名排序以保持结果稳定；不跟随目录软链。
2. 排除目标文件；若目标位于扫描根子树，排除其所属的直属子目录。仅排除根下该子树，不误排其他位置的同名目录。目标在扫描根本层或根外时，不排除其他子树。
3. 按 Markdown 标题切段，标题或正文含任一种子词时纳入；种子匹配区分大小写。
4. 中文按 `[\u4e00-\u9fff]{2,8}`、英文按 `[A-Z][a-zA-Z]{2,}|[A-Z]{2,}` 提词，统计频次。
5. 过滤种子词、通用词和占位词，按词频降序返回 Top N；同频沿用首次出现顺序。

这是正则切词，不是中文分词器：长中文串会被切段，小写英文不进入候选。扫描阶段保留注释文本；phase 2 匹配正文时才移除 HTML 注释。

## 调优

| 现象 | 调整 |
| --- | --- |
| 候选过泛 | 用更具体的种子，或缩小 scan-dir |
| 候选太少 | 检查大小写、目录与章节内容，再考虑增加 top-n |
| 本应命中的文件未扫描 | 检查目标子树排除规则及目录软链 |

调参授权见 [gates.md](gates.md)。扫描失败报错退出；零候选仅表示本次算法无结果。
