# 上下文共现算法详解

## 算法概述

通过统计种子关键词周边章节中的词频，找出与种子词语义相关的候选词。具体做法是：在扫描目录下找到所有包含种子词的 Markdown 章节，提取这些章节中出现的词语并统计频率，频率越高说明与种子词共现越多、语义相关性越强。

## 算法步骤

1. **扫描阶段**：遍历 `--scan-dir` 下所有 `.md` 文件（排除目标文件所在子目录）
2. **章节匹配**：按 Markdown 标题（`#` 开头）切分文件，找到包含任意种子词的章节
3. **词语提取**：从匹配章节中提取中文词组和英文术语
4. **词频统计**：Counter 统计所有匹配章节中的词频
5. **过滤排序**：排除停用词和种子词本身，按频率降序取前 TOP_N 个

## 词语提取规则

- 中文词组：正则 `[\u4e00-\u9fff]{2,8}`（2-8 个连续汉字）
- 英文术语：正则 `[A-Z][a-zA-Z]{2,}|[A-Z]{2,}`（驼峰词或全大写缩写）

## 调优建议

- 种子词越具体，候选词质量越高（如"计费规则"比"计费"更精准）
- 如候选词质量差，可尝试增加 `--top-n` 或更换种子词
- 停用词表可在脚本 `collect_candidates` 函数的 `stopwords` 集合中扩展
- 扫描目录越聚焦，噪音越少（可用 `--scan-dir` 指定子目录）
