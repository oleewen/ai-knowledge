# docs-archive 设计原则

与 [anti-patterns.md](anti-patterns.md) 互补；**操作层易错点**见上级 [gotchas.md](../gotchas.md)。

---

## 原则

1. **方案确认门禁**：未确认方案确认书前不写目标终稿；防范围蔓延与难回滚。
2. **来源不入正文**：追溯信息留在方案确认书或冲突清单，目标正文不堆出处脚注。
3. **结构服从目标**：标题层级与体例以目标文档/目录为准，不强行保留来源章节顺序。
4. **冲突显式处理**：来源或目标矛盾时不得静默合并；分步请用户裁决。
5. **先读后写**：读 overview、链接目标章节与同级体例，再映射与落盘。
6. **闸门合规**：受管路径须符合 [AGENTS.md](../../../../AGENTS.md) 与 [CONVENTIONS.md](../../../rules/CONVENTIONS.md)。
7. **不替代 docs-build**：不在本技能内编造或批量维护实体 ID 与 `KNOWLEDGE_INDEX` 链上字段。
