# 设计原则

反模式见 [anti-patterns.md](anti-patterns.md)；操作层 [gotchas.md](../gotchas.md)。

1. **确认门禁**：确认书未肯定 → 不写目标终稿。  
2. **来源不入正文**：追溯在确认书或冲突清单。  
3. **结构服从目标**：层级与体例以目标为准。  
4. **冲突显式**：矛盾须分步裁决，勿静默合并。  
5. **先读后写**：overview、目标章、同级体例读完再映射。  
6. **闸门合规**：[AGENTS.md](../../../../AGENTS.md)、[CONVENTIONS.md](../../../rules/CONVENTIONS.md)。  
7. **不替 docs-build**：不编造/批量维护实体 ID 与 KNOWLEDGE_INDEX 链字段。
