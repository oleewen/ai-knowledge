# docs-archive 核心概念

术语与路径约定；**闸门**见 [gates.md](gates.md)，**步骤**见 [workflow.md](workflow.md)。

## overview 指定语法

**模式**：`{overview}` 或 `{overview}#{章节/锚点}`

| 字段 | 含义 | 示例 |
|------|------|------|
| overview | 仓库内 overview 文件路径（必填） | `system/architecture/overview/billing-overview.md` |
| 章节/锚点 | 可选，仅归档该范围 | `#支付域`、`#refund-flow` |

---

## 目标路径如何确定（overview 驱动）

- 目标取自 overview **表格行内副标题链接**，**不接收**用户另行指定的额外目标路径（除非会话已改走非标准路径并在方案确认书中写明）。
- 路径含空格须加引号。
- **缺失链接**：列入冲突清单，逐条请用户决策；不得猜测落盘。
- 解析结果须写入方案确认书，不得仅停留在口头理解。

---

## 「来源—目标」简写

若用户使用「来源 {分隔符} 目标」简写，须先解析两端再读文件；分隔符与路径中含 `-`、空格或与数字相邻时易误切分，应改用 `→` / `到` 或给路径加引号，并向用户确认两端边界。详见上级 [gotchas.md](../gotchas.md)。
