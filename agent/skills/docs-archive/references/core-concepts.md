# 核心概念

## 来源与目标

- 来源：overview 文件或 overview 加锚点。
- 标准目标：overview 表格行内副标题链接。
- 锚点只限制本轮读取范围，不改变目标解析规则。
- 目标章节应与同层 README 和章节结构一致；不一致时停问。

## 第三列 delta

- [A]：新增归档要点。
- [U]：更新归档要点。
- [D]：删除说明，必须先改目标章节。
- —：无待归档 delta。

各类 delta 的回写规则见 [workflow.md](workflow.md#3-写目标章节)。

## 简写与路径

先解析来源和目标，再读文件。路径含空格时加引号；短横线、空格、数字相邻时使用“到”或箭头，避免误切。
