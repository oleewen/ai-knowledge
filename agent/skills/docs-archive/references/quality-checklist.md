# 质量清单（步骤 5～6）

### 结构

- [ ] 标题级与姊妹文件一致  
- [ ] 表、列表惯例一致  
- [ ] 站内链为合法相对路径（[links-and-index.md](links-and-index.md)）

### 来源清理（若剪切）

- [ ] 确认书已写清策略（删 / 索引壳 / 不动）  
- [ ] overview 无断链、半句悬空、「只有标题」段  
- [ ] 索引壳不承载业务事实，仅指目标章

### 语义与冲突（三类）

| 类型 | 含义 |
| ------ | ------ |
| 内部 | 同文档前后矛盾 |
| 目标侧 | 与目录内他文矛盾 |
| 来源对齐 | 结论有依据；来源自矛盾不静默合并 |

任一类问题：**停扩范围**，列冲突点（位置、摘录、描述、可选 A/B）。

### 冲突节奏

一次一决策点（或强绑定二选一）；选定后改文并复查本条；若正文保留两说，须标不确定或「待业务确认」（与用户约定一致）。

### 收口（5～6）

- [ ] 当前确认书已收口再落盘  
- [ ] 目标结构与同级一致  
- [ ] 矛盾已解或已标注并获认可  
- [ ] 导航/索引如需已更  
- [ ] 未擅自扩范围  
- [ ] 会话末变更摘要；未自动 commit/push
