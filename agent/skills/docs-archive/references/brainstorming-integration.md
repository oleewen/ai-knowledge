# 与多方案 / brainstorming 节奏的衔接

本技能**默认交付**仍是「方案确认书 → 目标落盘」，不是独立 `/brainstorming` 会话；但**澄清与方案对比**与其节奏对齐。

---

## 何时单问、何时多方案

| 场景 | 建议 |
|------|------|
| 范围、冲突策略、来源清理未清 | [workflow.md](workflow.md) 步骤 1：**一次只问一个**（选择题优先）。 |
| 存在真实可选路径（切块方式、清理力度、是否分批） | 步骤 2：至少 **2～3 种方案**，利弊 + 推荐项。 |
| 长澄清链、门禁进度表 | 会话 spec 可使用与 `sdx-*` 同构的进度表；锚点指向**本会话稿内**小节，示例见 [sdx-solution 会话模板](../../sdx-solution/assets/solution-session-spec-template.md)「门禁进度」。 |
