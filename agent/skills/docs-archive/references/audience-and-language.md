## 主读者

归档决策人和目标章节维护者。

## 宜写 / 宜弱化

| 宜写 | 宜弱化 |
| --- | --- |
| 确认书中的范围、映射、冲突、回写策略和推荐 | 正文中的来源审计信息与操作过程 |
| 体例一致的章节正文、有效链接和 delta 闭环 | 索引壳中的业务事实、未决裁决冒充定论 |

## 反例

| 避免 | 推荐 |
| --- | --- |
| 将“来源路径 + 待确认判断”直接并入业务正文 | 正文只写已确认事实，证据与待裁事项留在确认书或冲突清单 |

## 特殊允许区

确认书或冲突清单可保留来源、审计信息和待裁事项；须标明状态，不能将其视为已确认的业务事实。
