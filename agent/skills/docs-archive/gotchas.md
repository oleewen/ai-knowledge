# 常见陷阱

- 确认书就是写前意图澄清；未获写前 C 不写目标。
- 批次确认后不重复六项全清单；单元只摘录目标与路径。
- C、M、G、S、F 需带上下文，不能裸发字母。
- 当前单元默认必须烤干；未收敛不推进下一单元。
- 来源路径与审计信息不入正文；追溯放确认书或冲突清单。
- 目标体例优先于来源标题。
- 冲突先列点，再给推荐和数字选项。
- D 必须先落实目标章节删除，再将 overview 第三列回写 `—`。
- 索引壳不能塞业务长文。
- 实体/ID/INDEX-GUIDE 第四章走 docs-build；术语与引用链走 docs-revise；全篇结构或 SSOT 去重走 docs-simplify。
