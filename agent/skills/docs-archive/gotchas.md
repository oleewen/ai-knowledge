# docs-archive 易错点

## 闸门

- **确认书 = 意图澄清门禁**：公共六项并入确认书，写前 `C` 一次收口；勿在批次确认后再逐单元重复六项全清单停顿。  
- 未获写前 `C` 就写目标 → HARD-GATE；即使用户催，也须方案摘要+风险+**明确同意**。  
- 受管路径勿抢跑 SDD/归档总确认 → 对 [CONVENTIONS.md](../../rules/CONVENTIONS.md)。  
- 步骤 5 前勿硬删 overview → 易断链；按行落盘自检后再清理；默认倾向**索引壳**。  
- 勿把写前意图澄清称作「写前 grilling」；`G` 仅写后深挖。

## 澄清与烤干

- 写前须标「当前阶段：意图澄清」；烤干须标「当前阶段：烤干」。  
- `C` 同符异义，禁止无横幅裸发动作字母。  
- 各当前单元**默认必须烤干**；未收敛勿自动推进下一单元。  
- 语义性问题先给结论、推荐与数字选项；非语义修订才可直改当前单元。

## 质量

- **来源不入正文**；审计信息放确认书/冲突清单。  
- 来源矛盾 → 列冲突点，分步裁决，勿静默选边。  
- 服从**目标**体例，勿照搬来源标题级。

## 路径

- 简写分隔符与 `-`、空格、数字邻接易误切 → 用 `→`/`到` 或引号，并确认两端。

## 范围

- 只写确认书已映射主题；扩大须先改确认书再获写前 `C`。  
- 目录若依赖 README/INDEX，收尾检查是否同步（[quality-checklist.md](references/quality-checklist.md)）。

## 分流

- 实体与 KNOWLEDGE_INDEX → **docs-build**（勿在此造 ID）。  
- 全库术语+引用链 → **docs-upgrade**。
