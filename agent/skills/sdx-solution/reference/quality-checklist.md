## 完整性

- [ ] **§1 背景与目标**：§1.1–§1.4 均有实质叙述或已标「不适用」；业务目标 G-n 可指回需求来源/原始材料
- [ ] **§2 范围与约束**：核心场景与角色覆盖主路径；§2.3 含 In/Out 与成功标准；§2.4 约束含交付节点或已标「无外部截止」
- [ ] **§3 影响与冲突**：§3.1–§3.3 与 §3.2 表一致；影响说明覆盖功能、数据、对外承诺、下游四类中与本需求相关的维度；§3.4 每个 C-n 有化解思路与成本
- [ ] **§4 思路与方案**：§4.1 解决思路可读；多方案时 §4.2 已填，单方案时已标「不适用」；§4.3 关键决策均有推荐、备选与理由
- [ ] **§5 风险与待定**：§5.1 每个 R-n 有可能性、影响与应对；§5.2 Q-n 表已更新（无待定则填「无」）
- [ ] **§6 交付计划**：§6.1 MVP 可讲清业务价值与依赖方向；§6.2 里程碑含日期或阶段、交付物、验收口径；MVP 依赖无环
