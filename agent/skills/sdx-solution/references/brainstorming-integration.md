# brainstorming 嵌入（sdx-solution）

## 会话 spec 路径

闸门中间稿须落在 **`{DOC_DIR}/superpowers/`**（不含 `requirements/**/specs/`）。契约：[session-spec-path.md](../../../references/session-spec-path.md)。

示例：`{DOC_DIR}/superpowers/YYYY-MM-DD-<topic>-sdx-solution.md`
## 与独立 `/brainstorming`

| | 独立 `/brainstorming` | 本技能阶段二 |
|---|----------------------|---------------|
| 主产物 | 常 `*-design.md` + `writing-plans` | `…-sdx-solution.md`；终稿 `SOLUTION-*.md` |
| 终态 | 常进实现计划 | **Qclose-1** → 阶段三分块定稿 |
| 硬门禁 | brainstorming 自定 | **sdx-solution [gates.md](gates.md)** |

**禁止**：以「已完成 brainstorming」为由跳过 Gn、门禁标记或 Qclose-1；默认不建 `*-design.md` 替代会话 spec。

另需独立设计 spec 时：另会话跑 `/brainstorming`，再在后续会话消费其结论。

## G{n} 内多方案

**触发**：本门禁结论依赖 ≥2 条真实路径（范围、化解、里程碑、风险应对等）。

仍在同一 **G{n}** 内：**2–3 套**业务命名路径 → 利弊、条件、推荐 → 四选项收口 → 写入「本门禁结论」与搁置理由。

- **Q-n**：补事实缺口；**本节**：事实足、决策分叉。

## 各门禁可能触发多方案（示例）

G1 目标排序、G2 In/Out、G3 化解路径、G4 主思路、G5 风险应对、G6 MVP 切法、G7 附录粒度等。**G4** 常与多方案，但任一 G{n} 需在门内对比再收口。
