# brainstorming 嵌入（sdx-solution）

本技能不再把 `/brainstorming` 作为“先独立产出设计文档，再进入写作”的默认前置阶段，
而是把 brainstorming 能力拆入**参数向导**与**Section Cycle**。
`grilling` 的公共能力契约见 [grilling-skill.md](../../../references/grilling-skill.md)；本文件只说明 brainstorming 与当前段循环如何协同。

| 维度 | `/brainstorming` | 本技能 |
| --- | --- | --- |
| 终态 | 常 writing-plans | 当前段 `grilling` 收口后进入下一段 |
| 作用点 | 方案定稿前 | 参数确认、段内发散、段内比选、前文回改 |
| 约束 | 独立设计节奏 | 不替代 [gates.md](gates.md) 的 `C/M/G/S/F` 段落推进协议 |

## 使用方式

- 参数不清时：用 brainstorming 缩小参数空间，帮助用户确认 `IDEA-ID`、范围、深度、起始章节。
- 当前段存在 ≥2 条真实业务路径时：在**当前段**内完成 2–3 方案比选，再继续写段。
- 当前段 `grilling` 打出缺口时：先判断是本段修订还是前文回改；当前段修订可直接收口，前文回改须先给推荐方案与数字选项，再等待用户选择。

**禁止**以「已完成 brainstorming」跳过当前段的 `grilling`、用户确认或前文回改后的重开校验。细则见 [workflow.md](workflow.md)。
