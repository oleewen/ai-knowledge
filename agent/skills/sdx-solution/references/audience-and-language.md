## 宜写 / 宜弱化

| 宜写（业务） | 宜弱化（留给下游设计） |
| --- | --- |
| 角色、场景、流程 | 类/接口/方法名 |
| 业务规则与边界（业务话术） | 表/字段、中间件名 |
| 成功标准、预期收益、里程碑与切换 | 技术栈、部署形态 |
| 协作依赖（团队/环节） | 模块名、协议类型 |

## 反例

| 避免 | 推荐 |
| --- | --- |
