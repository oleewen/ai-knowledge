# 受众与语言（sdx-solution）

> 公共检查维：[受众与语言](../../../references/audience-and-language.md)。本文只定义本技能差额。

## 主读者

架构与产品，评审交付包的切分依据、边界与协作关系。

## 宜写 / 宜弱化

| 宜写 | 宜弱化 |
| --- | --- |
| 有知识依据的取舍、范围、流程衔接、数据使用关系与技术例外 | 实体字段全文、需求清单、实现细节和技能操作说明 |

## 反例

| 避免 | 推荐 |
| --- | --- |
| 复制接口字段以解释范围 | 引用已核实 PD，说明纳入/排除的职责与原因 |
| 基准未读就写「无技术例外」 | 先核实公司基准及 TS，再说明例外或确认无例外 |

## 特殊允许区

「技术例外」可说明相对公司模板的方案级差异及其 TS 依据，不展开实现设计。
