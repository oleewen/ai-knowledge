## 主读者

业务负责人、产品与方案架构，评审目标、产品职责边界、跨产品协作、风险与交付退出条件。

## 宜写 / 宜弱化

| 宜写 | 宜弱化 |
| --- | --- |
| 有知识依据的取舍、范围、流程衔接、数据使用关系与技术约束 | 实体字段全文、需求清单、实现细节和技能操作说明 |

## 反例

| 避免 | 推荐 |
| --- | --- |
| 复制接口字段以解释范围 | 引用已核实 PD，说明纳入/排除的职责与原因 |
| 基准未读就写「无技术例外」 | 先核实公司基准；再说明约束、例外或确认无例外 |

## 特殊允许区

技术约束与例外可在 §2.3、§3.2、§5.2、§7.1 表达，说明相对公司基准的方案级差异；不展开实现设计。
