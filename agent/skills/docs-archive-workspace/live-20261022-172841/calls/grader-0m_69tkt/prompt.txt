1. 按 `category`、`prompt` 和各断言的 `check` 判断语义；`expected_output` 是参考，不要求逐字匹配。

3. `passed` 必须为 JSON 布尔值。证据不足时判 `false`，并在 `evidence` 说明缺失内容；不得用断言 ID 代替证据。
4. `evidence` 必须为非空字符串，引用回答片段或说明判断依据。对「不得」类断言，可说明未发现冲突及相关上下文。
