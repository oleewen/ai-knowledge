- 3 个场景是行为抽样，其他 10 个用例本轮未运行模型；不声称全量行为通过或统计成功率。
- 运行器调用日志不覆盖全部读取工具；临时目录和访问约束不是操作系统沙箱。未对真实全局安装树执行安装。
- 模型读取的是维护说明调整前的运行副本；执行期间修复了顶层隐藏缓存枚举。模型场景未包含顶层隐藏缓存，该边界由最终脚本回归验证，未另作模型复测。
- 既有工作树另有根索引和共享脚本改动；本轮仅修改本技能，快速回归反映当时整个工作树状态。本轮未执行 Git 提交或推送。
