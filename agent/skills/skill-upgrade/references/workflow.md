# skill-upgrade 工作流

## 盘点与分类

默认 global；用户指定项目或具名技能时，保留该范围。先确认实际安装目录、软链目标与对应 lock；global 常见位置为 `$HOME/.agents/skills` 和 `$HOME/.agents/.skill-lock.json`，不能将该约定套到所有安装方式。

| 状态 | 依据 | 动作 |
| --- | --- | --- |
| 有源 | lock 可读，记录与已装技能对应 | 检查远端；未检查时标「更新状态未核实」 |
| 缺源 | 已装技能没有来源记录 | 列入补源候选 |
| 来源失效 | 已核实来源删除、迁移或不再提供该技能 | 保留原来源证据，列入补源候选 |
| 检查失败 | 网络、限流、认证异常，或 lock 不可读/格式不兼容 | 报告原错误；不改 lock、不推定无源 |
| 本仓管理 | 安装来源或软链目标证实属于本仓 Agent 树 | 分流 agent-install；同名不足以判定归属 |

读取技能目录与来源前后不得改动它们。来源不明的软链或目录保留待决策；发现本地修改时列明覆盖风险。

## 形成计划

参数约定与 CLI 能力检查见 [parameters.md](parameters.md)。计划至少包含：

| 技能 / 安装目标 | 来源与检查证据 | 动作 | 状态 / 待决策 |
| --- | --- | --- | --- |
| 实际路径与技能名 | lock 来源、远端检查结果或未核实原因 | 更新 / 补源 / 跳过 | 已确认 / 待确认 / 阻塞 |

此处 dry-run 指编排层只读预览，不是 CLI 参数。只读 lock 得到的是候选清单，不能称「将更新 N 项」或「已经最新」。本地只读任务不为查帮助而自动下载或执行远端 CLI。

缺源或来源失效且允许搜索时，进入 [find-source.md](find-source.md)；拒绝搜索则记录跳过。检查失败项保留原来源，可在用户允许后复查。

## 执行与核验

按 [gates.md](gates.md) 收口计划后：

1. 记录待改技能及 lock 的执行前状态；有本地修改时先确定保留或覆盖方案。
2. 按计划逐项执行。补源安装已完成该项操作时，不再无条件全量 update。
3. 任一命令失败即停止后续写入，列出已成功、失败和未执行项；不自动重试、换源或回滚。
4. 对照命令输出、安装内容与 lock 验证所选项及实际写入范围。退出码成功但结果无法核实时，标「未核实」。
5. 给出结果与剩余决策，完成受众 A/B 后停在轻流程动作点。失败后的重试或恢复须说明具体动作，沿用仍有效的授权；额外覆盖须重新确认。
