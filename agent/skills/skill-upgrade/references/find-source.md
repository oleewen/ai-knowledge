# 缺源与失效来源的补源

仅处理 [workflow.md](workflow.md#盘点与分类) 中的缺源、已核实来源失效项。网络或认证失败不进入自动换源流程。

## 搜索许可

列出技能名、原来源与原因，询问是否搜索；已有明确许可则沿用。拒绝时记录跳过，不搜索、不安装。

允许后，若环境已有 `find-skills`，按其发现流程检索；不可用时使用已核实的生态 CLI 或官方来源检索，不自动安装辅助技能。

默认按本地技能名搜索，再核对描述、功能、来源和维护状态。安装量、星数只能辅助判断，不能证明同源。首次无结果可提出调整查询；继续扩大搜索须获同意，无有效结果则记「未找到」。

## 候选与决策

| 结果 | 呈现方式 |
| --- | --- |
| 唯一候选，名称及功能一致，来源有证据 | 建议项，说明匹配依据；仍须确认 |
| 多候选、名称或功能不一致、来源证据不足 | 待决策表，列候选差异 |
| 无候选 | 未找到；保留原技能 |

不设默认可信 owner 白名单，不将同名或声誉视为同源证明。用户指定来源也须确认它提供目标技能。

汇总为「本地技能｜候选来源｜匹配证据｜覆盖影响｜用户选择」。用户可选候选、手动指定来源或跳过；多候选不得擅自定源。将已选来源和准确安装命令并入总计划，按 [gates.md](gates.md) 执行。
