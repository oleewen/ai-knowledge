# docs-change 设计原则

与 [anti-patterns.md](anti-patterns.md) 互补；**操作层易错点**见 [../gotchas.md](../gotchas.md)。

---

## 原则

1. **零幻觉**：只收录可验证数据；不编造提交或文件变更。
2. **时间精确**：统一毫秒精度比较；展示格式统一为约定字符串。
3. **增量一致性**：新条目插入最前，历史不删，文末基线必须更新。
4. **幂等性**：相同输入与基线下结果一致。
5. **优雅降级**：Git 或部分 CHANGELOG 不可用时跳过该源，整体流程继续。
6. **下游契约**：每条记录带来源标签，便于 `docs-indexing` / `docs-build` 消费。
