# sdx-test 易错点

| 现象 | 处理 |
| --- | --- |
| `--file` 相对路径定位错误 | 相对调用目录解析；需要时使用绝对路径 |
| 无参扫描包含旧迭代或其他目录 | 既有扫描范围为整个 DOC_DIR；只检查当前稿时使用 `--file` |
| 没找到 TDD 或缺配置 | 区分退出码 3（未校验）与 2（配置/运行错误），均不算通过 |
| 受限稿引用了不存在的 DSD | §1.1 记录真实缺口，不保留伪路径来满足追溯检查 |
| 简表缺步骤或可判断预期 | 在行内或同组说明补齐；详见 [内容原则](references/design-principles.md) |
| 六类 TC 数量看似充分，回归仍有遗漏 | 按变更影响面核查来源与断言，不以条数代替覆盖 |
| 复制模板后误写“测试已通过” | §5 是计划门槛，§6.2 是设计自查；均不构成执行报告 |
| 原样复制模板内相对链接 | 按输出文件位置生成实际引用，不带入技能目录路径 |

流程与产物误用见 [anti-patterns.md](references/anti-patterns.md)。
