主干：[SKILL.md](../SKILL.md)。门禁：[gates.md](gates.md)。

## 阶段一（参数）

一次抛出（支持快捷改）：**IDEA-ID**、**MVP Phase N**、门禁 **6G / 精简 4G**、`--depth`。须与 PRD/DSD 路径一致。

## 门禁状态机

```
[阶段二：逐门禁]
    全量 6G：G1→…→G6
    精简 4G：G(1–2)→G3→G4→G(5–6)
[Qclose-1] → C/S：PENDING→CONFIRMED
[阶段三] 骨架 → chunk 1–6（精简则 4 chunk）→ 终检
```

| 精简门禁 | 全量 | 模板 |
|---------|------|------|
| G(1–2) | G1、G2 | §1、§2 |
| G3 | G3 | §3 |
| G4 | G4 | §4 |
| G(5–6) | G5、G6 | §5、§6 |

每门禁：草案 → （可选）多方案 → 确认 → 收口；末附 **C/M/S/F**。

## 回跳

| 依赖 | 处理 |
|------|------|
| 强 | 与 G{k} 矛盾或同实体（同 US/TC、同回归范围）→ 须重确认 |
| 弱 | 大量引用 G{k} 术语/范围/优先级 → 建议重确认 |
| 无 | 可保持 |

例：回改 G2（用例/优先级）→ G3/G5 常强；回改 G1 范围 → G2–G5 多弱重审。用户选「仅强」或「强弱一并」。

---

## Q-n 协议

**触发**：任一门禁歧义、矛盾或信息缺口。

- 单次一题；选项写清含义，禁「方案A/B」。
- 结论写入对应门禁草案；**S** 时标搁置与影响。
- **Q-n 优先模式**（可选）：全部门禁草案后集中澄清，再 Qclose-1。

---

## G{n} 填充要点

### G1 §1

读 PRD（US、验收、BR、NFR）；有 **DSD**/specs 则取 API 与影响面（可读 **ASD**）。§1.1 链 PRD/DSD/ASD 与 MVP-N；§1.2 新增/变更/回归对齐 DSD 影响面；§1.3 层次与覆盖与 §5 互证。`depth`：quick 压策略；standard 全；deep 加强性能/并发/安全（视 NFR）。

### G2 §2

§2.1 功能：US-n、TC-{NNN}；§2.2 接口：DSD §2 / 规约 API，含正常/参数/权限/幂等/并发，**TC-API-***；§2.3 **BR-n**，**TC-BR-***；§2.4 异常 **TC-EX-***；§2.5 性能：deep 或 NFR 需要时写，否则「不适用」；§2.6 回归与 §1.2 一致，**TC-REG-***。

| depth | G2 |
|-------|-----|
| quick | P0 功能 + 核心接口；异常/回归从简 |
| standard | 六类齐全 |
| deep | 性能、安全、并发加细 |

### G3 §3

数据类型、量、关联、准备方式；边界与特殊值；外部依赖 Mock/Stub。

### G4 §4

版本与 **DSD** 部署一致或说明差；Mock 可执行。

### G5 §5

进入：代码/单测/环境/数据可检查项。退出：通过率、缺陷档、覆盖、性能（若适用）可度量。回归顺序：核心 → 直接 → 间接。

### G6 §6

§6.1 变更历史；§6.2 质量自查；文首 frontmatter 必填。
