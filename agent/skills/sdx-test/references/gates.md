# sdx-test 推进绑定

共享协议：[写前意图澄清](../../../references/intent-clarify.md)、[单元推进](../../../references/unit-cycle-protocol.md)、[写后烤干](../../../references/grilling-skill.md)。参数、容器与写后默认表见 [workflow.md](workflow.md)。

## 当前段

TDD 六章中一个章节、子章节，或单个功能/接口/业务规则/异常用例组、数据准备块、环境块、进出标准块、回归范围块。动作使用 `C/M/G/F`，无 `S`；不复制共享状态机。

## 追加澄清字段

在公共六项清单中补充：

- PRD 与 DSD/ASD 对齐点；缺 DSD 时的范围收窄或技术基线盲区。
- `IDEA-ID`、MVP、`depth` 与当前段的覆盖目标。
- 需要决策的真实测试策略、预期行为或进出标准。

## 停顿与重开

| 情况 | 约束 |
| --- | --- |
| 当前段意图未确认，或缺口影响预期结果 | 不写正文 |
| 烤干未收敛 | 不推进下一段 |
| 范围、预期结果、优先级、回归边界、数据/环境或进出标准变化 | 先给结论、推荐与数字选项，确认后修订 |
| 影响前文或上游追溯 | 按共享协议重开受影响对象，旧确认不自动继承 |
| 用户选 `F` | 使用共享协议的剩余意图批确认；保留已确认前文 |
| 请求变为测试代码或执行报告 | 明确切换任务范围，不继续以 TDD 写作代办 |
| 结构校验失败、未运行或空扫描 | 不宣称结构通过；任何结构结果都不代表产品测试通过 |
