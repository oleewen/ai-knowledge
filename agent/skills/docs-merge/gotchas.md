# docs-merge 常见陷阱

遇到异常时先定位原因；完整规则见 [merge-spec.md](references/merge-spec.md)。

| 症状 | 检查点 |
| --- | --- |
| 完整双路径命令仍被反复追问角色 | 位置参数已定义顺序；只核对真实语义冲突 |
| 计划凭空多出“章节” | 是否把围栏、引用或 frontmatter 内标题当作正文结构 |
| 同名 H3 落错业务域 | 是否比较父 H2 的完整路径 |
| 再合入一次仍有相同更新 | 是否先比较正文覆盖关系，而非仅比较标题 |
| 无标题内容被贴到文末 | 是否遗漏落位选择；不能以文末作为默认目标 |
| 首次正式执行要求两次写前 C | “重新 C”只针对模式切换或计划前提变化 |
| 等 C 才问冲突，又要求无冲突才能 C | 先逐项收口内容决议，再汇总六项取得正式 C |
| 确认期间他人修改消失 | 是否仍用旧基线写回或盲目回滚 |
| 合入后链接失效 | 是否按目标位置换算相对链接并处理引用式定义 |

结构校验通过不代表行为正确；复现方式见 [evaluation.md](references/evaluation.md)。
