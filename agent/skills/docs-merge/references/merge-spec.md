# docs-merge 合入规范

主干：[SKILL.md](../SKILL.md)。流程：[workflow.md](workflow.md)。

## 1. 解析 source / target

1. 收位置参与可选 `--dry-run`。
2. **target**：须已存在 `.md`；不存在 → 中止。无法判定谁是 target → 停问。
3. **source**：已存在文件 → 读全文；否则内联文本。路径/正文两可或像拼写错误 → 停问。
4. 单参且像已存在 md → candidate target，补收 source。

## 2. 切分源块

按源内 H2/H3 切块；无标题则整段一块（落位必问）。块内列表/表/代码围栏原样迁入，除非目标节要求改写。

## 3. 落位（H2/H3）

1. 规范化标题（去编号、空白、大小写折叠）比对目标树。
2. 唯一命中 → 计划落位该节。
3. 多候选 / 无候选 → 停：候选或新建（可改标题、挂靠父级）+ 数字选项。

未落位须在**写前澄清**收口。未落位非空 → 不得给正式写入的写前 `C`（dry-run 可展示未落位计划）。

## 4. 类似判定（同节内）

| 条件 | 动作 |
| --- | --- |
| 无标题近似且无关键句/实体明显重叠 | **新增**（确认后） |
| 标题规范化相等或词重叠达近似 | **合并候选** |
| 无标题但关键实体/状态/API 等重叠显著 | **合并候选** |

边界不清 → 合并候选并标「待确认」。

## 5. 合并与冲突

- 无冲突：去重留完整表述，补缺，保目标节层级。
- 有冲突：grilling 一条一条（结论 + 推荐 + 选项，进度 `k/N`）。
- 禁止未授权的全局「源胜/目标胜」打包覆盖（显式授权须记入写前 C）。

## 6. 落盘

1. `--dry-run`：合入计划三分区（新增 / 合并候选 / 未落位），可附冲突预告；**不写文件**。
2. 正式：落位已确认 + 写前 `C` + 冲突全决 → **一次**写回 target；失败整文件回滚。
3. **不改源**。
4. 落位未确认或冲突未决 → 禁止落盘（禁止边决边写）。

## 7. knowledge 目标

target 在 `application|system|company` 下 `*/knowledge/**` 时：正文/链接/路径字面量守 [knowledge-governance.md](../../../knowledge/knowledge-governance.md)「业务 knowledge 引用边界」。库外文档链 → 留字去链或实体 ID；不明则停。
