# 受众与语言（docs-merge）

公共维与烤干门禁见 [受众契约](../../../references/audience-and-language.md)。

## 主读者

目标文档维护者。

## 宜写 / 宜弱化

| 宜写 | 宜弱化 |
| --- | --- |
| 计划中的完整章节路径、增量、计数和未决问题 | 全文堆叠、无法定位的“已处理” |
| 当前项的原文与拟改差异、推荐及选项 | 一次抛出多项待批 |
| 目标正文中的业务表达 | 合入过程、确认口令与决策记录 |

## 反例

| 避免 | 推荐 |
| --- | --- |
| “已合并”，却没有实际差异证据 | 说明写入或无写入、采纳/跳过结果与验证 |
| 在 knowledge 正文贴库外 ADR 链 | 按 [合入规范 §8](merge-spec.md#8-knowledge-目标) 摘录已核实要点 |

## 特殊允许区

无。
