# docs-merge 核心概念

算法：[merge-spec.md](merge-spec.md)。

| 术语 | 含义 |
| --- | --- |
| `<source>` | 位置参：已存在路径或内联文本 |
| `<target>` | 已存在单个 `.md` |
| `--dry-run` | 只出合入计划 |
| 合入计划 | 新增 / 更新 / 未落位 |
| 变更清单 | 待新增 A、待更新 U、合计 N；逐项提问前先公布 |
| 章节落位 | 挂目标 H2/H3（非文风/frontmatter 对齐） |
| 逐项流转 | 清单中每项：提问 → 用户决策 → **再进下一项** |
| 源只读 | merge ≠ move |
