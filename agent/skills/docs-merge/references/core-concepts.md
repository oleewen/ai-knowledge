# docs-merge 核心概念

规则定义见 [merge-spec.md](merge-spec.md)；此处只解释术语。

| 术语 | 含义 |
| --- | --- |
| 源块 | 按 Markdown 结构切分的材料单元，不一定产生变更 |
| 落位 | 源块在 target 中对应的 H2/H3 完整路径 |
| 变更项 | 可独立采纳或跳过的一项增量；新增或更新 |
| 无变更 | 目标已覆盖的相同信息，不进入待确认项数 |
| 未落位 | 尚无确定目标节的源块，不计入新增/更新 |
| 基线 | 制定计划时读取的源与目标内容，用于识别确认期间变化 |
| 落盘集 | 全部决议结束后，已明确采纳的变更项集合 |
