# 受众与语言（docs-distill）

> 公共维与烤干门禁：[audience-and-language.md](../../../references/audience-and-language.md)

## 主读者

系统库 overview 维护者；第三列供系统/公司视角读者核对应用已核实知识。

## 宜写 / 宜弱化

| 宜写 | 宜弱化 |
| --- | --- |
| 已核实应用知识的业务表述同步 | 未核实猜测、本地未合并草稿 |
| 与 overview 行对齐的增量说明 | 应用内部类名/接口当系统知识正文 |
| DISTILL-LOG 可审计摘要（overview 成功后） | 先写 LOG 后改 overview |

## 反例

| 避免 | 推荐 |
| --- | --- |
| 把 application 实现细节原样上行 | 转成系统 overview 可读业务/能力表述 |
| overview 失败仍追加 LOG | overview 成功后再追加 |

## 特殊允许区

无。
