# 反模式与纠正

| 反模式 | 纠正 |
| --- | --- |
| 参数未收口就写盘或预览 | 先确认 `DOC_DIR`、`--name`、模式和单一目标 |
| 跳过写前 `C` | 输出公共六项与职责/粒度摘要，获 `C` 后再执行 |
| 从正文猜职责或粒度 | 只读 `knowledge-governance`、目标表行、`knowledge-layout`、槽位 README |
| 契约缺失或冲突仍继续 | 硬停，给数字选项；结论先落盘 |
| 把非槽位资料当蒸馏源 | 转 `docs-extract`；归档转 `docs-archive` |
| 仍使用 `--since` 或写 `DISTILL-LOG` | 拒绝该路径；模式恒为全量 |
| 槽位空、未 pull 或缺 README 仍写 | 停，先补联邦挂载与契约 |
| 把槽位原文、OpenAPI、整段 DDL 塞入第三列 | 按目标层表行提炼能力摘要 |
| 已覆盖要点再次复制 | 读目标第三列后只写 delta |
| 新建 overview 只改文件名 | 同步替换标题中的 `{NAME}` |
