# docs-distill 推进协议（binding）

主干：[SKILL.md](../SKILL.md)。本文件只声明本技能的单元、追加字段、风险和原子性；共通动作与状态机见 [unit-cycle-protocol.md](../../../references/unit-cycle-protocol.md)。

## 当前单元

一个 `{NAME}-overview.md` 加一次全量范围。一次只处理一个源名称；收敛前不得自动切换另一源或另一边。

## 写前追加字段

公共六项之外，澄清必须包含：

- `DOC_DIR`、知识层、`--name`、源槽位和目标 overview
- 正式写入或 `--dry-run`
- overview 是新建还是更新
- 职责、表行粒度、跨层收束摘要及其契约锚点
- 对应实体或章节的证据记录及 `{DOC_DIR}/governance/evidence/` 写入范围

明确的只读请求在契约齐备时直接预览；正式写入须核对写前授权，既有同范围有效授权不重复索要。预览不授予正式写入权限。

## 高风险

先给结论、推荐项和数字选项，再执行：

- 创建或替换影响超出已确认范围，或与旧待归档项冲突
- 槽位缺失、为空、挂载失效 或缺 README
- 职责/粒度契约缺失、模糊或双边冲突
- 目标层与槽位内容冲突且无法按既有规则消解

职责/粒度未闭合时必须先落盘契约；在此之前不得 dry-run。

## 原子性

- 业务写入限目标 overview 第三列；新建时允许从模板复制并替换 `{NAME}`。同批次按 [知识证据登记](../../../knowledge/knowledge-evidence.md) 维护来源版本、预期目标实体或章节及当前缓冲位置，不扩写业务正文。
- `--dry-run` 不写 overview 或证据。
- 不写 `DISTILL-LOG` 或全量运行史，不接受 `--since` 或 `--full`；持久证据登记不属于运行日志，不能省略。
- 写前保存来源、overview 与证据的读取版本；每次替换前复核，发现并发变化停止并重新核对。先登记待落盘证据，再写第三列；证据或 overview 部分失败时报告实际状态并停止推进，恢复只限可证明未被后续修改的本轮差异。具体边界见证据规范；不得假称跨文件原子提交。
- 槽位前置条件不满足就停，不用源仓直读绕过。
- 写入或预览后必须烤干；未收敛不得宣称完成。

证据元数据使用[共享生命周期工具](../../../knowledge/knowledge-evidence.md#工具生命周期)：先 `create` 登记待落盘，实际目标完成后 `update` 绑定字节哈希与人工结论，`check` 通过后才按当前单元规则推进。来源变化用 `refresh` 标记，版本变化新建并接续前序编号；部分元数据写入按原操作 ID `resume`。该工具不代写正文或 overview，也不以元数据操作完成替代当前单元验收。
