# docs-distill 与多方案 / 澄清节奏

本会话主产物为 **`…-docs-distill.md` 会话 spec**、经门禁后的 **`{APPNAME}-overview.md` 更新**与 **DISTILL-LOG** 记录，**不以**独立 `/brainstorming` 常见的 `docs/superpowers/specs/*-design.md` + `writing-plans` 作为默认终态。

---

## 与 sdx 阶段二同构的节奏

- **单次一个待确认点**：范围、`--since` / `--full`、冲突处理策略，逐项澄清后再收口。详见 [interaction-gate.md](interaction-gate.md)。
- **多方案对比**：当存在 ≥2 条真实路径（例如不同增量起点、是否拆分多批蒸馏）时，在阶段 2–3 内完成 2–3 套对比，再请用户选主路径；避免未对比即默认全量。
