# docs-distill 行为评分

按 [evals.json](../evals/evals.json) 的当前请求及适用断言评分，检查实际响应、命令与文件，不以计划或技能名称代替行为证据。

- should-trigger：核对实际 DOC_DIR 与知识层、槽位边、契约依据、全量范围、第三列 delta 及执行模式。
- should-not-trigger：核对主路径分流正确且未执行额外 distill 写入。
- 明确的只读请求不要求额外写前 C；实际契约缺失或冲突仍阻止语义预览。正式写入检查有效授权，已有同范围授权不重复索取。
- 任一适用断言失败则整例 fail；无失败但有未执行或无证据断言则 not_run；全部适用断言有证据通过才为 pass。未到达阶段说明不适用原因。

输出 `text`、`status`（pass/fail/not_run）、`evidence`；逐条记录断言 id、状态及可定位证据。只读/无改动需核对前后字节，异常路径需观察实际非零退出；校验脚本成功不证明职责契约或正文蒸馏完成。

独立评测只给技能、真实请求和隔离原始输入，隐藏预期答案；保存实际响应、工具轨迹和文件差异。目录访问限制不是操作系统沙箱。当前仅运行前置检查时，不要求伪造正文、烤干或归档产物。
