# docs-extract 交互与确认闸门

与 `docs-distill` 采用**同一话语体系**（中间会话 spec → 用户总确认 → 落盘）；**差异**在于：docs-extract 无增量锚点，每次均为全量提炼，HARD-GATE 触发条件相对简单。

**目录**：[与 docs-distill 对齐](#与-docs-distill-对齐的约定) · [HARD-GATE 触发条件](#hard-gate默认禁止落盘) · [会话 spec 与门禁标记](#中间会话-spec-与门禁标记) · [推荐交互节奏](#推荐交互节奏)

---

## 与 docs-distill 对齐的约定

| 概念 | 对齐方式 |
|------|----------|
| 中间会话 spec | 路径：`docs/superpowers/specs/YYYY-MM-DD-<topic>-docs-extract.md` |
| 用户总确认 | 会话 spec 文末标记由 `PENDING` 改为 `CONFIRMED` |
| 合法例外 | 用户在同一会话中**明示**跳过闸门、仅要预览、或授权直写 |
| 预览优先 | 触发 HARD-GATE 时，**先** `--dry-run`，再谈是否落盘 |

---

## HARD-GATE（默认禁止落盘）

在取得**用户总确认**之前，**禁止**执行步骤 3（写入 overview 第三列）。

**允许**的步骤：步骤 0–2 的参数校验、关键词读取、段落筛选与命中预览；以及**仅预览**的 `--dry-run`。

下列**任一**成立即进入 HARD-GATE：

| 触发条件 | 执行者动作 |
|----------|------------|
| 首次为某 overview 写入内容（overview 存在但第三列全为 `—` 或空） | 先 `--dry-run` 预览将写入的章节与内容摘要；总确认后再写入 |
| 命中段落数量异常多（> 50 个段落命中） | 警告可能存在关键词过于宽泛；建议用户收窄关键词后再执行 |
| 源文件包含敏感路径（如 `.env`、`credentials`、`secret` 等文件名） | 警告并请用户确认是否继续，不自动跳过 |
| overview 第三列已有大量内容且本次将触发多处 `[U]` 更新（> 10 处） | 先 `--dry-run` 展示变动摘要；总确认后再写入 |
| 步骤 3 写入**失败** | 不做部分落盘，整体回滚；提示用户重试 |

## 中间会话 spec 与门禁标记

**路径**：`docs/superpowers/specs/YYYY-MM-DD-<topic>-docs-extract.md`

**文末标记**：

- 总确认前：`<!-- docs-extract-gate: PENDING -->`
- 用户总确认后：`<!-- docs-extract-gate: CONFIRMED -->`

**文中至少写明**：`--sources` 路径列表、`--overview` 目标路径、命中段落数量与归属章节摘要、是否已执行 `--dry-run` 及结论摘要。

---

## 推荐交互节奏

1. **上下文探索**：读取 overview 关键词附录，确认关键词覆盖范围；扫描源文件列表，评估内容规模。
2. **触发 HARD-GATE 时**：先 `--dry-run`，展示命中段落摘要与将写入的变动列表。
3. **单次一个待确认点**：优先选择题或「范围 / 风险 / 授权」三要素之一。
4. **用户总确认后**：执行步骤 3 写入；失败则整体回滚，不做部分落盘。
