# docs-extract 常见陷阱

## 关键词附录

- **无 `## 文档关键词`**：须停机补全，**禁止**用章节标题猜词。
- **词过宽**（如「系统」「数据」）：命中爆炸 → 警告收窄。
- **词与业务脱节**：应用真实术语（如理赔/保单），非泛化技术词。

## 段落筛选

- **勿扫 overview**：4.1 只处理 `--sources`。
- **代码块**：通常非业务知识，勿当摘要写入。
- **标题单行**：不单条提炼，跟随后文。
- **短段**：<20 词须 ≥2 关键词进候选（见 extract-spec）。

## 写入

- **跳过写前意图澄清**：不得在未输出六项清单、未获写前 `C` 时写入或输出正式预览；见 [intent-clarify.md](../../references/intent-clarify.md)、[gates.md](references/gates.md)。
- **dry-run 仍须澄清**：预览前也要意图澄清；烤干可针对预览结果。
- **第三列**：提炼摘要，非粘贴长原文。
- **A/U/D**：新增/实质改/删 须标对；无变化不加标。
- **无命中章节**：禁止用 `—` 盖掉已有内容。
- **写前**：读该节「应填内容 + 产出建议」。
- **4.3 失败**：整体回滚，勿部分落盘。

## 源文件

- 条目为路径时：隐藏路径默认跳过，除非用户指定。
- 条目为路径时：二进制跳过并在预览说明。
- 对“路径型 sources”做存在性校验；对“文本型 sources”不做校验。
- 条目疑似路径但不存在时，先停下提示用户确认（避免把拼写错误当作文本）。
