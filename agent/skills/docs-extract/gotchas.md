# docs-extract 常见陷阱

## 关键词附录

- **无 `## 文档关键词`**：须停机补全，**禁止**用章节标题猜词。
- **词过宽**（如「系统」「数据」）：命中爆炸 → 警告收窄。
- **词与业务脱节**：应用真实术语（如理赔/保单），非泛化技术词。

## 段落筛选

- **勿扫 overview**：4.1 只处理 `--sources`。
- **代码块**：通常非业务知识，勿当摘要写入。
- **标题单行**：不单条提炼，跟随后文。
- **短段**：<20 词须 ≥2 关键词进候选（见 extract-spec）。

## 写入

- **第三列**：提炼摘要，非粘贴长原文。
- **A/U/D**：新增/实质改/删 须标对；无变化不加标。
- **无命中章节**：禁止用 `—` 盖掉已有内容。
- **写前**：读该节「应填内容 + 产出建议」。
- **4.3 失败**：整体回滚，勿部分落盘。

## 源文件

- 隐藏路径默认跳过，除非用户指定。
- 二进制跳过并在预览说明。
- 阶段 1 校验**所有** `--sources` 存在，缺则终止列路径。

## 自查

- [ ] sources/overview/附录 OK；未扫 overview
- [ ] 命中量合理；无代码块当业务知识
- [ ] 仅改有命中节；写前已读产出建议；A/U/D 对；失败已回滚
