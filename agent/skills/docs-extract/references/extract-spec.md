# docs-extract 提炼规范

布局契约：[knowledge-layout.md](../../../references/knowledge-layout.md)。关键词附录、段落筛选、第三列写入。**流程**见 [workflow.md](workflow.md)。

## 关键词附录格式

overview 须含 `## 文档关键词`「章节 → 关键词」表。章节名与目标 overview 主标题对齐：

- **系统库**：`system/knowledge/overview/NAME-overview.md` 表行（见各视角 README）
- **公司库**：`company/ea/overview/NAME-overview.md` 表行（见 `company/ea/` 各视角 README）

- 手工维护业务术语；多章可共用词；段落归 **命中密度最高** 章（平手按五视角顺序）；附录标题固定 `## 文档关键词`。

## 段落筛选

**切分**：`\n\n` 分段；`#` 标题单独成段；代码块整块不切。

**命中**：分词 → 计数关键词（不区分大小写，可部分匹配）→ 密度 = 命中词数 / 段词数 → 密度 > 0 进候选 → 归属密度最高章节。

**阈值**：默认至少 **1** 个关键词；**<20 词**短段至少 **2** 个；标题行不单筛，跟随后文。

## 提炼写入

与 distill **overview 第三列**语义对齐。

**步骤**

1. 读五视角索引表
2. 逐节读副标题对应章节的「应填内容」「产出建议」
3. 从该章命中段提炼，改为系统库表述
4. 第三列：`—`/空 → 写内容 + `[A]`；有内容且实质变化 → `[U]`；应删 → `[D]` 清空；无变化 → 不动
5. 无命中章节：**不改**，不写 `—`

**撰写**

- **先读后写**；可多段/列表/小表；**不**整段复制；**不**在正文写 `(来源：…)`（追溯放 spec）
- 密度低的长段 conservative；提炼不出有效信息则不强填

## 自检

- 附录存在非空；命中来自源文件，不含 overview 自扫
- 仅更新有命中章节；A/U/D 与实际一致；摘要非粘贴；第三列无实现级噪音（大段 DDL/代码/原始故事等）
