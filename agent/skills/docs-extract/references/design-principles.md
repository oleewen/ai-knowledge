# docs-extract 设计原则

| 取舍 | 原因与规则位置 |
| --- | --- |
| 用目标附录筛选 | 避免来源自带术语扩大目标知识范围；见 [关键词附录格式](extract-spec.md#关键词附录格式) |
| 命中后仍比对知识正文 | 词匹配不证明事实新增；见 [提炼写入](extract-spec.md#提炼写入) |
| 只改当前 delta | overview 是待归档容器，旧项与无命中行须保留；同上 |
| 证据独立登记 | 来源版本与目标映射持久保存，业务正文只可留证据编号；见 [知识证据登记](../../../knowledge/knowledge-evidence.md) |
| 单文件完整替换，跨文件分别核对 | 降低半写和覆盖并发编辑的风险，不假称批次原子提交；见 [落盘与失败](workflow.md#落盘与失败) |
