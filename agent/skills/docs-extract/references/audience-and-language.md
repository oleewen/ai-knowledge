# 受众与语言（docs-extract）

> 公共维与烤干门禁：[audience-and-language.md](../../../references/audience-and-language.md)

## 主读者

overview 维护者与后续归档/蒸馏读者；第三列须可被业务/系统视角消费。

## 宜写 / 宜弱化

| 宜写 | 宜弱化 |
| --- | --- |
| 与关键词相关的业务事实、可核对摘录 | 无命中空写、臆造 ID/路径 |
| A/U/D 影响面说明（含 dry-run 预览） | 把源文档全文粘进第三列 |
| 会话中的来源位置与核对依据 | 第三列中的来源文件路径、脚注或整段实现细节 |

## 反例

| 避免 | 推荐 |
| --- | --- |
| 无命中仍改 overview | 无命中结束单元，禁止空写入 |
| 把设计文档 API 表整段塞入 | 按相关度提炼业务语义句 |

## 特殊允许区

会话中的命中摘要可列来源文件与段落位置供维护者核对；这些路径不写入第三列。dry-run 也须让维护者看懂新增、保留与冲突。
