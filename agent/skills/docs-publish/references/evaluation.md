# 发布评测

结构检查、脚本回归与模型行为分别报告。用例见 [evals.json](../evals/evals.json)；对每项断言记录 pass / fail / not_run 和证据。有失败则用例 fail，无失败但未验证则 not_run；全部断言有证据通过才为 pass。解释场景可评价回答，操作场景须核对真实调用和产物，不能仅按关键词判分。

脚本回归在仓库根运行 `bash agent/skills/docs-publish/tests/run.sh`（Bash 5+）。测试只在临时仓与本地 bare 远端运行发布，禁止指向真实托管远端。覆盖版本、白名单、真实预览后执行、内容/暂存/日期/远端变化拒绝及 autostash 冲突现场保留。

独立行为评测给新代理当前请求、冻结运行技能和临时原始文件；不提供预期、评分器或未来消息。发布执行只通过绑定临时仓、本地 bare 远端的运行器，明确限定授权；不触及本仓或真实账户。多轮先保存预览及文件快照，再投递用户后续授权或状态变化，不让代理模拟未来回复。

保存用户输入、响应、参数、退出码、文件与 Git 状态。计划失配、未合并索引或依赖缺失时，核对是否如实停止，不能自动重新取计划并视为已授权。仅测试脚本不等于模型行为通过；抽样范围外标记 not_run。访问约束不是操作系统沙箱。
