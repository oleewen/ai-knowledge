# 常见阻塞

| 情况 | 处理 |
| --- | --- |
| 在主分支或 detached HEAD 上运行 | 停止；切到用于发布的 feature 分支后重新 dry-run |
| 四层版本缺失、非法或不一致 | 停止；修复版本字段后重新预览，不手工猜版本 |
| 存在白名单外工作树改动 | 停止；不要把无关文件并入发布提交 |
| 根级或层内 `TODO-LIST.md` 未在预览中明确纳入 | 不加入发布范围；先重新 dry-run 收口 |
| fetch、rebase、认证、分支保护或 push 失败 | 保留现场并报告失败阶段；不自动重试、回滚或强推 |
| 预览后工作树、分支或远端状态变化 | 原确认失效，重新运行 dry-run 并重新确认 |

版本发布只处理发布脚本列出的文件。若目标是模板对齐、内容升级、结构重组或术语修订，应转到 `/docs-upgrade`、`/docs-simplify` 或 `/docs-revise`。
