# sdx-domains 反模式

| 误用 | 正确处理 |
| --- | --- |
| 将域架构写成七章方案、生成日期主题 ID | 使用已有 BD-ID 与总图/分域模板 |
| 总图和所有分域一次覆盖 | 以确认的映射块或章节为当前段；批量推进见 [gates](gates.md) |
| 缺 knowledge 就从需求补造实体 | 报告缺口；实体建设属于独立任务 |
| 按文件名推断 BSD 层级或 PL 归属 | 核实实体关系及依据，PL 保持纯 ID |
| 借 `F` 重写已确认前文 | `F` 补齐剩余；明确重写请求走重开 |
| 脚本退出 0 就称业务完成 | 继续核对 [质量清单](quality-checklist.md) |

运行问题见 [gotchas.md](../gotchas.md)。
