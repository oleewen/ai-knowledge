# sdx-domains 质量验收清单

按本轮范围检查实际文件与 diff；部分章节通过不等于整稿完成。

## 总图

- [ ] 每行 VC/BD 已核实，支撑关系有依据。
- [ ] 分域链接指向已存在文件；待生成项有标记，没有伪造链接。
- [ ] 映射与分域已确认内容一致，未静默覆盖其他行。

## 分域

新稿按四节模板检查；旧稿按标题与内容定位本轮授权段，不套用新章号。旧稿缺少的其他主题列为后续缺口，不自动补章。

- [ ] 文件名、frontmatter id 与对应 BD 已核对；历史命名未被自动迁移。
- [ ] 价值链与 BD `supports_to` 一致。
- [ ] 支撑说明中的 BSD-L1/CAP、层级与关系均有依据。
- [ ] 范围与非范围明确；PL 仅用核实的纯 ID，未确定则标缺口。
- [ ] 新稿符合 [模板](../assets/domain-template.md)；旧稿只在本轮范围内修改，未被强制重排。

## 共同验收

- [ ] 未新增 knowledge 实体或代写下层方案/需求；没有七章方案、日期主题 ID 等串用。
- [ ] 未把待确认事项写成事实；没有无来源的归属、边界或承诺。
- [ ] 通过 [受众检查](audience-and-language.md) 和 [gates](gates.md)；语义变更已确认。
- [ ] 已运行本轮文件校验；整稿收口时运行全量校验，并报告未决项。

脚本只能验证 [机械检查项](workflow.md#校验脚本)，不能替代上述语义核对。
