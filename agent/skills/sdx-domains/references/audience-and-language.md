# 受众与语言（sdx-domains）

主读者是公司架构治理、业务域负责人和产品负责人。回答：哪条域支撑哪条价值链、由哪些一级子域承担、边界在哪、对接哪条 PL。

- 保留 VC/BD/BSD-L1/CAP/PL 的准确 ID，必要时附业务名称；不把 ID 当实现噪声删除。
- 关系字段用于核对证据，正文解释业务职责；不扩写类、接口、表字段或中间件方案。
- 不为简化技术用语而删除已确认的可测约束；超出公司域范围的内容另行定界，不凭空新增「内部技术参考」章节。

烤干按 [共享受众契约](../../../references/audience-and-language.md) 的 A/B/C/E 检查；语义改变遵守 [gates.md](gates.md)。
