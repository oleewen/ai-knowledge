# ASD 联邦概要（`KNOWLEDGE_TYPE` = system | company）补充说明

拆分为 **ASD + DSD** 后，系统库/公司库中的 **ASD 仅撰写 §1、§2**（见 [asd-template.md](asd-template.md)），**不在 ASD 中出现**历史单文档 ADD 意义上的「§3 详细设计 / §4 需求规约」大段占位。

实现级接口、DDL、业务逻辑与 **`specs/*.yaml`** 在**应用知识库**通过 **`/sdx-design`** 产出 **DSD** 并评审确认后再视为终稿。
