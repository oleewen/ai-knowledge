# 受众与语言（sdx-architect）

> 公共维与烤干门禁：[audience-and-language.md](../../../references/audience-and-language.md)

## 主读者

**架构师**（主笔与验收）；**分析、产品、研发**参评可行性与范围。

## 宜写 / 宜弱化

| 宜写（ASD） | 宜弱化 |
| --- | --- |
| 边界、组件依赖、关键取舍 | 类/方法实现与源码 |
| 协议约定、领域/数据归属 | 完整 OpenAPI/DDL、单测代码 |
| 发布约束、影响、下游承接 | PRD 故事全文、调优细节 |

## 反例

| 避免 | 推荐 |
| --- | --- |
| 大段粘贴 PRD 用户故事 | 引用 US-n / FR-n，说明对应架构决策 |
| 内部调用链当主叙述 | 说明系统间边界与责任；实现细节由 DSD 承接 |

## 特殊允许区

模板 §2.2、§2.4 允许协议与逻辑数据关系摘要，不展开实现字段。业务意图以已确认 PRD 为准。
