## 变更与依据

| 项目 | 结论与修订 |
| --- | --- |
| 环境授权 | 停用 `FORCE`、`CREATE_PROJECT_ROOT` 默认值；只有显式 `--force`、`-r` 启用重装或建工程根。保留 `SCOPE`、`MODE` 环境默认值；同步帮助与迁移说明 |
| 依赖前置 | knowledge 缺 Perl 时在写入前返回非零，预览也阻塞；config 不依赖 Perl |
| 失败传播 | 路径改写、README 注记保留原错误与非零退出；不把部分复制当作安装完成，保留原内容备份 |
| 真实权限错误 | 独立审查发现 Perl 原地编辑可能只警告并返回 0；真实目录权限用例复现后将该警告转为失败。共享调用方 docs-upgrade 同样停止，不再误报收尾完成 |
| 预览表达 | 非空目标无 force 也展示重装影响，供用户审阅；明确区分计划展示、会话授权和执行标志，保正文转 docs-upgrade |
| 评测 | 保留 16 个原用例，新增环境授权多轮和缺 Perl，共 18 个；原部分失败例补真实执行变体。判分改为 pass/fail/not_run，保留证据与失败记录 |

新增脚本用例 27–30 均先观察到失败再修复：环境变量越权重装、缺 Perl 继续执行、路径/注记错误被吞、真实 Perl 权限警告返回零。独立复审重跑真实权限场景及正常升级收尾，未发现剩余可操作问题。
