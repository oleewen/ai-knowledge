# docs-build 与 brainstorming / SDD 的边界

`docs-build` 的会话 spec 与 Qclose-1 与 **sdx-*** 同形，但**主交付**是 `{DOC_DIR}/knowledge/` 下 **schema 2.1 实体资产**，不是 `SOLUTION-*` / `ASD-*` 等 SDD 终稿。

---

## 何时应离开本技能

- 仅要根目录 `INDEX_GUIDE.md` → **docs-indexing**。
- 仅写系统 `overview` 第三列 → **docs-distill** / **docs-extract**。
- 从 overview 归档到视角章节 → **docs-archive**。
- 元模型/schema 大版本升级、跨仓合并策略 → 先设计/评审再回到 manifest 与提取规则。

---

## 可借用的形式

「单次一个待确认点」「门禁进度表锚到本会话稿」与 sdx 一致；示例见 [`sdx-solution` 会话模板](../../sdx-solution/assets/solution-session-spec-template.md)。将 gate 前缀换为 `docs-build` / `docs-build-gate`。
