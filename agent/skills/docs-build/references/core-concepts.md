# 核心概念

| 对象 | 职责与真源 |
| --- | --- |
| 实体文件 | 每实体一个 `{ID}.md`；[okf-spec.md](../../../knowledge/okf-spec.md) 定义结构 |
| 视角 README | 本层实体台账与阅读入口；不承载实体长正文 |
| 层根 INDEX 第四章 | 静态视角导航；不扫描或复制实体表 |
| knowledge/index.md | OKF 目录导航，由 docs-okf 维护 |
| 首次定义层 / 目录宿主 | 见 [knowledge-governance.md](../../../knowledge/knowledge-governance.md) 与 [knowledge-layout.md](../../../references/knowledge-layout.md)；有宿主目录不代表可复制上层实体 |
