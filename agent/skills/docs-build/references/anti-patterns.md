# docs-build 反模式

| 误用 | 正确处理 |
| --- | --- |
| 将实体构建等同九章索引重建 | 先分流；build 只写第四章导航 |
| 把所有规则与 meta 一次全读 | 按当前层、视角、错误类型加载 |
| 将脚本成功当作实体事实已核实 | 继续证据与关系语义审查 |
| 用重提覆盖人工正文、用删除修复冲突 | 保留有效内容，按 [builtin-config.md](builtin-config.md) 收口 |
| 将写前澄清称为 grilling | 写前确认范围，写后烤干；[gates.md](gates.md) |

具体症状与修复见 [gotchas.md](../gotchas.md)。
