# docs-build 验收清单

按[统一校验规范](../../../knowledge/knowledge-validation.md)核对结构、确定性关系与必需引用；事实真实性另列。工具尚未统一实现，不能仅凭退出码宣称收敛，未覆盖项须补核或标明未执行。

## 写入与来源

- [ ] 主 INDEX、DOC_DIR、知识层与当前单元已明确，写前确认覆盖实际变更。
- [ ] 模板/示例与业务实体已区分；规则基线、源快照、身份上下文和范围完整性可定位。
- [ ] 写前授权包含实际证据路径；按[证据规范](../../../knowledge/knowledge-evidence.md)先登记待落盘记录、再写实体，并用实际字节补齐目标 SHA-256、核验状态和有效依赖承接；`--emit-report=false` 未省略证据。
- [ ] 每个 ID 有已读来源；达到选定置信度；缺父级/证据的候选未落正式实体。
- [ ] 只写本层实体；实体 Profile、命名及路径遵各自真源。
- [ ] 增量保留有效人工内容；旧 ID 未擅自重命名或删除。

## 提取语义

- [ ] 对选定来源检查 Dubbo Provider、HTTP、MQ Consumer、Job；不存在的类型说明未发现，不补造。
- [ ] MS 按宿主类聚类，模块可有多个宿主；MQ 同一 Consumer 多 Tag 不拆多个 API。
- [ ] ENT 按已核实物理表身份去重，不把不同数据源同名表混为一个。
- [ ] 关系、证据与知识引用边界正确；范围外应核实的反向边列待办，消费方 `PD.uses_to SYS` 的派生 `used_by` 不误判为缺少人工回写。

## 台账与导航

- [ ] README 行来自实体文件，链接有效；本层无实体时说明，无示例冒充。
- [ ] 实体/README 预检通过后才归并；层根 INDEX 中仅更新第四章导航块。
- [ ] 已运行现有完整模式结构检查并补核已知缺口；输出中警告和旧规则误报已逐项核实，未静默删除旧文件或改变 ID。
- [ ] 旧工具的非零结果与原诊断完整报告；治理元数据格式误报仅单项人工复核，未豁免其他错误。生成器不兼容新治理容器时停止受影响生成，未将证据或操作记录收入实体图/台账。
- [ ] 先判实体再验字段，错/缺 type 未绕过 Profile；按完整身份核对唯一性，文件名、字段映射、title/tags/timestamp、H1 与四段正文及逻辑层一致。
- [ ] 必需本地引用的目标、锚点与允许范围有效；确定性失败未降为警告。

## 章节交接

- [ ] 接单证据、归属与授权已核实，overview 候选未自动当作事实；失败未清理原 delta。
- [ ] 交付实体版本与证据目标哈希一致；证据未完成或部分写入已列状态，未把旧章节标为采用新实体版本。
- [ ] 直接实体变更也已在确认范围定位受影响摘要；有 overview 交 archive，无 overview 交 docs-revise，无影响说明检查范围。
- [ ] 未越权写章节；交接续写同一 TODO，未提前勾销或宣称全链闭合。

## 人工终检

- [ ] 必填关系、合法边、两端至多一的既有 1:1 约束及适用反向关系已核验；「多个」未误作最少两个，必填性另按 meta。
- [ ] 跨层 HTTP 形式、外库可读性与目标/关系核实分开报告；不可读未被判为不存在，相关删除、迁移、注销未提前闭环。
- [ ] 结构、确定性关系、必需引用和事实真实性分别列状态；未执行不等于通过，模板通过不替代业务实体兼容证据。
- [ ] 按 [audience-and-language.md](audience-and-language.md) 通过受众维 A/B/C/E。
- [ ] 报告变更、校验范围和未闭合项；烤干收敛后停等下一动作。
