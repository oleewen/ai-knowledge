# 易错点（docs-simplify）

## 澄清与烤干

- 写入前先意图澄清（六项 + 阶段横幅）；未获写前 `C` 勿写正文。
- 各当前单元**默认必须烤干**；未收敛勿自动扩批。
- 勿把写前澄清称作 grilling；`G` 仅写后深挖。

## 精简

- **过猛砍约束**：验收/例外必留（B3）。
- **空壳标题**：标题要能当结论读。
- **只删句不重组**：仍须 A1/A2，否则「短但乱」。
- **模板硬结构**：SOLUTION 等固定七章 / G·C·R·Q 表 / 自查清单 → 只砍散文，不拆章刷短；行数降幅有限正常。
- **自查改外链**：示例内自洽清单默认留；改链到模板须确认。

## SSOT

- **相似≠同一真源**：全仓扫后必须人确认（C3）。
- **默改他处正文**：默认只改当前文件为引用。
- **误伤 C4**：ID、契约 frontmatter、代码字面量、扫描列；`updated` 日期可刷新。
- **仅文件内复述**：无外仓命中时，压缩本文件交叉叙述即可，勿虚构外链 SSOT。

## 分流

- 术语 `X→Y` 主诉求 → `docs-upgrade`。
- 双目标 → 问顺序，勿静默双跑。
