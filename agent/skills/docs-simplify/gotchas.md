# 易错点（docs-simplify）

## 澄清与烤干

写前授权与写后确认是不同阶段。已有本单元授权不重问，revise 的写后确认不自动授权新的 simplify 单元；详见 [gates.md](references/gates.md)。

## 精简

保留固定模板与可执行信息；表密文档不追求行数降幅。检查 [质量清单](references/quality-checklist.md)，勿只删句不重组。

## SSOT

相似不等于同一事实。候选须确认、真源路径须核实；knowledge 引用先查治理边界。默认仅改当前范围内的引用方。

## 分流

纯术语纠错走 `docs-revise`。协议内 simplify 遍不启动完整技能环；revise `grilled` 后的独立改写可限制 hunk。已给定双目标顺序无需重问。

## 自查

按 [质量清单](references/quality-checklist.md) 验实际 diff；边界反例见 [anti-patterns.md](references/anti-patterns.md)。
