# 反模式（docs-simplify）

通用 A/B/C 规则见 [精简原则](../../../references/simplify-principles.md)。本页只列执行边界反例。

| 反模式 | 正确处理 |
| --- | --- |
| 限定 hunk，却顺手删同文件旧段 | 旧段只作上下文，diff 留在已确认片段 |
| 小范围精简也强制全仓扫描 | 围绕当前事实按需查重 |
| 双目标顺序已给，仍再问一次 | 沿用已明确顺序 |
| 已确认三文件批次，逐文件再问 | 一个批次作为一个单元 |
| 两段措辞相似就认作同一真源 | 列出事实差异、候选和拟处置，待确认 |
| 模板表多、降行少就判失败 | 检查叙述冗余与可执行信息 |
| 去重后只剩外链，读者无法验收 | 保留对象职责内的必要判断信息 |
