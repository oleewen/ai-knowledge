# 反模式（docs-simplify）

原则 SSOT：[docs-simplify.md](../../../references/docs-simplify.md)。

| 反模式 | 为何错 | 应做 |
| --- | --- | --- |
| 背景铺垫很长才到点 | 违反 A1 | 结论先行，细节下沉 |
| 同级标题交叉复述 | 违反 A2 | MECE 重组 |
| 入口堆全量细节 | 违反 A3 | 链接下钻 |
| 空壳「概述/说明」标题 | 违反 A4 | 标题写结论 |
| 一段多主题 / 句内多意 | 违反 B1 | 拆段拆句 |
| 砍掉验收/约束「显得短」 | 违反 B3 | 激进只砍废话 |
| 拆固定七章/删编号表刷短 | 违反模板硬结构 | 只砍散文，留骨架与 G/C/R/Q |
| 未确认把自查改成外链 | 失示例自洽 | 须人确认 |
| 未确认就删重复段改链接 | 违反 C3 | 先列候选等人确认 |
| 改实体 ID / 扫列表「顺手整理」 | 违反 C4 | 默认禁改（日期类除外） |
| 把术语替换当精简 | 分流错误 | 走 docs-upgrade |
| 跳过澄清直接全文件重写 | 门禁错误 | 写前 C 后再写 |
| 以行数 KPI 判烤干失败 | 表密文档误判 | 看可读与可执行 |
