# sdx-analysis 质量验收清单

对照实际正文、原始材料及 diff 核验；模板 §7.4 只勾已核实项。局部任务只检查当前段与依赖，不宣称全篇完成。

## 内容

| 部分 | 通过条件 |
| --- | --- |
| §1 | 现状与需求分开；G-n 有目标、度量、预期收益及来源；未定指标明确列缺口 |
| §2 | 主场景、角色、范围内外与成功标准可核对 |
| §3 | 能力、影响传播一致；覆盖相关功能/数据/对外承诺/下游；每 C-n 有策略、成本、残余风险 |
| §4 | 业务思路可读；约束表包含交付条件或已确认的「无外部截止」；多方案取舍可追溯 |
| §5 | 每 R-n 有可能性、影响和应对；Q-n 只记业务决策并区分状态；技术决策按 gates 处理 |
| §6 | M{n}（短名）有覆盖范围、前置、交付物、验收、退出；仅需试点/切换者建 §6.2 行；依赖无环 |
| §7 | 术语与已引来源齐全；技术线索限 §7.3 并标「待研发确认」；自查如实勾选 |

## 跨段与格式

- [ ] 与原始材料及已读知识无未解释冲突；每目标、冲突、风险、决策和里程碑可指回来源、约束或范围。
- [ ] 编号连续或已解释跳号；已有 ID 和跨段引用未受破坏；MVP/FR 留给 FEATURE。
- [ ] [受众检查](audience-and-language.md) 通过；业务化改写保留数值、单位、时限、例外及承诺。
- [ ] frontmatter 的 id、title、version、status、created、updated、author、parent、dependencies、tags 齐全；id 与文件名一致。
- [ ] 全篇收尾时，七章及小节与 [模板](../assets/analysis-template.md) 一致；无内容处注明不适用或待补充，未决项不冒充通过。
- [ ] [技术决策门禁](gates.md#技术决策绑定) 满足；引用指向实际存在的文档，无 ADR-待定。
- [ ] 已运行 [脚本](../scripts/validate-analysis.sh) 并审阅诊断；结构校验、业务审阅与用户写后确认分别报告。
