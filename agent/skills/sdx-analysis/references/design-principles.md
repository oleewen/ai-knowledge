# sdx-analysis 写作原则

结构与精简遵循 [共享精简原则](../../../references/simplify-principles.md)；本页只补需求分析的判断标准。

- **证据与建议分开**：区分现状、期望能力和拟议方案；目标、冲突、风险可追溯到输入或已读资料。未知事实标「待确认」。
- **问题留在当前段**：材料不足先补影响本段的缺口；不默认扩成整篇重写。真实多方案比较业务收益与代价，不凑选项。
- **影响按相关性覆盖**：检查功能、数据、对外承诺和下游协作；无关维度说明不适用，quick 仍保留高影响。
- **正文面向业务**：按 [受众要求](audience-and-language.md) 转述实现线索，保留已确认的数字、单位、边界与验收承诺。
- **按需取证**：从索引下钻当前段所需资料，不通扫知识树。没有知识库基线时注明缺口，不伪造引用。

章节结构见 [模板](../assets/analysis-template.md)，验收仅见 [quality-checklist.md](quality-checklist.md)，推进与 ADR 归属见 [gates.md](gates.md)。
