# sdx-analysis 评测失败分析

根据失败案例、裁判证据与实际 diff 提出最小修复。先读 [evaluation.md](../references/evaluation.md)；再按失败点读取 [SKILL.md](../SKILL.md)、[workflow.md](../references/workflow.md) 或 [gates.md](../references/gates.md)。

| 类型 | 检查重点 |
| --- | --- |
| 发现或路由 | 未加载、误触发、知识层或下游产物混淆 |
| 授权或推进 | 重问已确认参数、未经授权写入、F 越界、回改后未重开 |
| 产物 | 覆盖原文、章节缺失、来源失真、指标丢失、ADR 重复或断链 |
| 评测本身 | 夹具缺失、证据不足、断言矛盾、历史结果冒充当前验证 |

每个问题只写：**观察证据 → 根因假设 → 最小改动位置 → 回归案例**。未证实根因标为假设；证据不足先补证据，不能把 incomplete 算失败来扩写规则。

优先修复越界写入、事实失真与错误分流。先复跑相关案例，再按影响选回归；不为单例新增无关的普遍限制。
