# 易错点

## 链式

- **过度统一**：仅形似而义不同 → **勿**并成一段；以主变更概念为准。  
- **「所有 X」**：确认范围后再扩关键词；一层不够时说明工作量/误改，勿无限 BFS。

## 关键词

- **短词/高频词**：命中爆炸 → 缩路径或让用户定模式后再替。  
- **近义边界**：批量前看上下文；疑 → 选项，勿默认全替。  
- **中英/缩写**：大小写、`API`/`api`、标题 slug 是否一并统一。  
- **注释**：勿破代码块 fence。

## 简写

- 一行多 `-`/`>` → 让用户加引号或改自然语言。

## 决策

- 无出处数字/版本/截止 → **选项**，勿编。  
- 无边界全库术语 → 先分批/排除目录，勿直接开改。

## 自查

- [ ] 先主改再引用链，未先全库替  
- [ ] 近义已核对上下文  
- [ ] 命中过多已缩范围或确认  
- [ ] 不可核实已编号问用户  
- [ ] 回链、fence OK
