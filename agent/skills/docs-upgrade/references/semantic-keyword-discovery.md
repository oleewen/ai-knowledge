# 关键词与语义（无直接链时）

用户要「全库统一说法」或主改含可重复术语/列表/摘要，而链式未盖全时，在引用链外增加本路径。

## 词面（分批 `rg`）

| 类型 | 说明 |
| ---- | ---- |
| 同义 | 语境可互换，如用户要求统一的「登录/登入」 |
| 近义 | 易混写；仅当用户意图为**统一表述** |
| 中英 | 缩写与全称、中英并列标题等 |

每轮维护**小词表**（用户原话、主文件术语、常见对），逐项搜后再判断是否该改。

## 何时开

- 用户点名统一品牌/API/配置键等  
- 主文件短语在他处以同义/略写/另一语言出现  
- 一层链未盖而 `rg` 仍有高置信命中  

## 策略

1. **高置信片段**：1–3 个不易误伤连续串（专名、带括号正式名、拼写修正…），`rg -F`。  
2. **扩同义/近义/中英**：逐项搜；命中爆 → 先 `docs/`、`{DOC_DIR}/` 或用户排除路径。  
3. **语义**：明显同一概念/同一列表项/复制段才改；疑 → [gates.md](gates.md) + [SKILL.md](../SKILL.md) 步骤 5。

## 顺序

**主改完成 → 引用链一层 → 再关键词**。禁止未读主文件就全库替。

## 风险

- 过短串、常见英文词 → 易误伤，须核对或缩范围  
- 生成代码、锁文件、构建目录 → 按 AGENTS/忽略排除
