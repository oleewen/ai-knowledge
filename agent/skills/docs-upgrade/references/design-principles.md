# docs-upgrade 设计原则

与 [anti-patterns.md](anti-patterns.md) 互补；**操作层易错点**见 [../gotchas.md](../gotchas.md)。

---

## 原则

1. **先确认再扩面**：多文件或大目录写入前须完成范围确认书（见 [gates.md](gates.md)）。
2. **主文件优先**：先完成主修改，再引用链，再关键词；避免未读主文件即全库替换。
3. **概念边界优先**：仅统一同一术语/同一列表项/复制段；不强行合并含义不同的近邻表述。
4. **可验证**：指标、版本、日期、责任人等无仓库出处时不编造，输出编号选项。
5. **链式可控**：默认一层入站+一层出站；扩展深度前提示风险与工作量。
6. **下游分工**：本技能不写 `CHANGE-LOG`、不重建 `INDEX_GUIDE`（见 [gates.md](gates.md) 分流）。
