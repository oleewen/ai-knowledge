# docs-upgrade 验证清单

落盘后抽查；用户要求时运行仓库既有校验命令。

---

## 结构与内容

- [ ] 链接可解析（相对路径、`#anchor`、反引号路径）
- [ ] 表格与代码块未破坏
- [ ] 术语与主目标一致；关联处与主变更概念对齐

---

## 与 gotchas 对齐的快速自查

更细项见 [../gotchas.md](../gotchas.md) 文末「快速自查清单」：

- [ ] 主文件修改完成后再做引用链检索
- [ ] 近义词命中已核对上下文
- [ ] 短词/常见词命中过多时已缩小范围或请用户确认
- [ ] 无法核实的内容已输出编号选项
- [ ] 回链校验已完成
- [ ] 代码块定界符未被破坏
