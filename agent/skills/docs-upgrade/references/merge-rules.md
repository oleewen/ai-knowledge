# docs-upgrade 合并规则

与 [SKILL.md](../SKILL.md) P0 契约一致；实现时以此为准。

## 1. 角色

| 侧 | 胜出域 |
| --- | --- |
| 元库 `{meta}/{doc_dir}/` | 目录骨架、脚手架、示例模板、md 的 H2/H3 **结构** |
| 本库 `DOC_ROOT` | 业务正文、实体、日志、已改文件内容、独有路径 |

## 2. 已改判定

对同相对路径：去掉行尾空白、统一 `\n` 后比较内容。

- 相等 → **跳过**
- 不等 → **已改**（md 进结构重填；非 md 见 §4）

## 3. 四桶（脚本清单）

| 桶 | 条件 | 写盘策略 |
| --- | --- | --- |
| 新增骨架 | 元库有、本库无，且非排除项 | 一批 `C` 后由 `--apply-scaffold` 复制 |
| 跳过 | 两边规范化后相同 | 无动作 |
| 结构重填 | 两边有、已改、且为 `.md` | Agent：元库 H2/H3 为骨，本库同标题节正文填入 |
| 本库独有 | 本库有、元库无该路径 | **保留不删**；清单注明 |
| 工具脚本 | 仅 `system`/`company`：`{META_ROOT}/scripts/docs-link.sh`、`link-config.sh` 相对 `{REPO_ROOT}/scripts/` 缺或内容不等 | 一批 `C` 后 `--apply-scaffold` **元库整文件覆盖**（备份后写入） |

排除（永不从元库装入目标）：根级 `DESIGN.md`、`CONTRIBUTING.md`；以及 `knowledge-links.yaml`（本库保活，不作骨架覆盖源）。

**联邦相关**：

| 规则 | 行为 |
| --- | --- |
| 顶层遗留 `application-*` / `system-*`（**不含** `application-slots` / `system-slots`） | 硬忽略；清单「忽略遗留槽位」 |
| 凡软链（文件或目录；路径自身或祖先） | **跳过**不跟随；清单「跳过软链」；禁止 scaffold/重填 |
| `application-slots/`、`system-slots/` 下非软链真文件 | **进入**四桶 / 结构重填（与普通路径同） |
| `application-slots/changelogs/**`、`system-slots/changelogs/**` | 本无 → 新增骨架；本有 → 跳过并标「changelogs·本库胜」（不进结构重填；文件模式强制也不破） |
| 槽位实例内容（软链目标仓） | 归 `/docs-pull`，本技能不跟随 |

application 的 README 映射：本库 `README.md` 对照元库 `README-s.md`（若无则 `README.md`）；不把 `README-c.md`/`README-s.md` 作为额外目标文件名写入（除非本库已有同名）。

## 4. 非 Markdown

- `knowledge-links.yaml`：**永不**被元库覆盖
- **建联工具脚本**（上表「工具脚本」）：例外，**元库整文件胜**（非「已改本库胜」）
- 其它非 md（在 `DOC_ROOT` 内）：已改 → 本库胜（清单记跳过覆盖）；元库新增且本库无 → 可进新增骨架
- 无 H2/H3 的 md：整文件本库胜；仅当本库无该路径时作新增骨架

## 5. 结构重填（Agent）

1. 以元库 md 的 H2/H3 为节序与标题骨架
2. 同标题（去首尾空白、层级相同）→ 用本库该节正文替换
3. 元库有、本库无 → 保留元库节（新模板节）
4. 本库有、元库无 → **未落位**，不得自动追加；进清单逐项确认（追加文末 / 并入候选节 / 跳过）
5. 全部未落位决完前，可先落「已对齐节」的中间稿，或等未落位决完一次落盘——默认：**对齐节可先写入**，未落位确认后再补写，避免长会话丢进度；备份已在 scaffold 步覆盖原文件

## 6. 确认粒度

- 整树一批写前 `C`：批准新增骨架 + 工具脚本覆盖 + 可对齐结构重填
- 文件模式：总览 `C` + 逐文件 `C`（见 [gates.md](gates.md)）
- 未落位：一次一项
- 本库独有文件：只报告，不删

## 7. 文件强制对齐（`@` 模式）

与整树互斥。输入与展开见 [parameters.md](parameters.md)；流程见 [workflow.md](workflow.md)。

对规范化后每条路径：

| 条件 | 动作 |
| --- | --- |
| 顶层遗留 `application-*` / `system-*`（非 `*-slots`） | **拒绝**该条 |
| 路径为软链或落在软链下 | **拒绝**该条；提示实例同步用 `/docs-pull` |
| `*-slots/changelogs/**` 且本库已有 | **整文件本库胜**（不强制重填）；总览注明 |
| `*-slots/changelogs/**` 且本库无、元库有 | **scaffold**（须该文件 `C`） |
| 元库无对应路径（README 映射后仍无） | **硬停该条**（报错；不猜替代）；其余路径可继续 |
| 两边都无 | **硬停该条** |
| 本库无、元库有 | **scaffold** 该路径（须该文件 `C`）；Agent 复制，不经脚本 `--path` |
| 两边有、且为 `.md`（非 changelogs 特例） | **强制结构重填**（破 §2「跳过」；契约同 §5） |
| 两边有、非 `.md`（非建联例外） | **不覆盖**；清单标「指定但非 md：不覆盖」 |
| 建联例外两脚本（`system`/`company`） | **元库整文件覆盖**（同「工具脚本」桶）；每文件 `C` |
| `@scripts/` 展开 | 只保留上述两文件名；其它忽略并注明 |

排除项仍生效：不把 `knowledge-links.yaml` 当骨架覆盖目标；根级 `DESIGN.md` / `CONTRIBUTING.md` 不从元库装入（与整树一致）。

文件模式不强制 `.docs-init` 备份。
