## 主读者

## 宜写 / 宜弱化

| 宜写 | 宜弱化 |
| --- | --- |
| 约定范围内的术语/表述统一 | 超范围顺手大改结构 |
| 沿引用链的必要同步 | 无依据改 ID、断链 |
| 范围确认书中的替换映射 | 把精简/归档主路径偷换成 upgrade |

## 反例

| 避免 | 推荐 |
| --- | --- |
| 替换后残留旧术语混用 | 链式扫引用与关键词 |
| 业务文被换成实现黑话 | 保持目标文档原读者口吻 |
