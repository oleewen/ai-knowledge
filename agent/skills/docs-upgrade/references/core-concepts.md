## 替换简写

trim 后 `a`→`b`（分隔符与 a、b 间可有空格）：

| 写法 | 含义 |
| ---- | ---- |
| `a - b` | a→b |
| `a > b` | a→b |
| `a 2 b` | a→b（2 = to） |

`|`、换行、边界糊 → 用引号：`"旧" - "新"`。`a` 不唯一 → 报命中数/样例或请用户是否全替。
