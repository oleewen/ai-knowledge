# docs-upgrade 风险控制与确认点

采用 [light-flow-actions.md](../../../references/light-flow-actions.md) 的 `C/M/S/F`（无 `G`，不绑定意图澄清），遵守 [CONVENTIONS.md](../../../rules/CONVENTIONS.md#artifact-gates)。本文件只定义确认时机，分类与内容写法见 [merge-rules.md](merge-rules.md)。

## 写前确认

先完成 [参数](parameters.md) 与 [源解析](workflow.md#源解析)，再展示整树 dry-run 清单或指定路径总览。未获当前范围的 `C` 不得写盘。

预览须足以核对以下事项：

| 公共信息 | 模式信息 |
| --- | --- |
| 文档目录、层级、meta 来源、ref、动作数量与已有文件改动 | 整树：当前 / 目标版本及发布 commit（如有版本），备份位置与路径收尾影响 |
| 覆盖 meta、预期不符或范围调整的结论与推荐选项 | 指定：完整并集名单、每项来源与动作、显式 `meta-only` 文件；提示无强制 `.docs-init` 备份 |

## 动作含义

| 动作 | 效果 |
| --- | --- |
| 清单 / 总览 `C` | 执行全部可处理项；有未落位则随后选策略，不默认要求逐文件确认 |
| 单文件 `C` | 同上，范围仅当前文件 |
| `M` | 改参数、名单或预览，亦可下钻单文件；新范围须重新确认 |
| 总览 `S` | 取消当前计划，不新增写入；已写盘不回滚 |
| 单文件 `S` | 跳过本文件并继续下一项；已写盘不回滚 |
| `F` | 仅在已确认前提与当前模式内推进，不把指定路径扩成整树 |

推荐预览出口：

```text
清单 / 文件 i/N：<路径、动作与改动摘要>
C 执行可处理项 / M 改参数、名单或下钻 / S 取消本计划或跳过本文件 / F 按当前模式推进
```

## 未落位策略

清单 / 总览或单文件 `C` 后，若存在未落位，**两种确认粒度均须**提供三档；对齐节可先写，未落位待策略确认后才写：

1. **批量文件并入**：当前范围内所有文件的未落位按原父级并入。
2. **单文件批量并入**：按文件轮转，每文件确认全部未落位按原父级并入；单文件 `C` 后仅处理该文件。
3. **逐项并入**：一次一项，选择原父级、改挂骨架父、原样追加文末或跳过。

并入形态见 [merge-rules.md §5](merge-rules.md#5-结构重填agent)。逐项可用：

```text
未落位 i/N：<相对路径> § <标题>；原父级：<标题或无>
1 用原父级 / 2 改挂骨架父 / A 原样追加文末 / S 跳过本项
```

选择改挂时再列可选骨架父。此处 `S` 只跳过当前未落位项；轻流程 `S` 不等于全跳过未落位。

## 写后停顿

按 [workflow.md](workflow.md) 校核产物并完成受众 A/B（指定模式整单一次）；版本推进须满足该文件的完整成功条件。未通过不得宣称完成。收敛后停等 `C/M/S/F`。
