# 受众与语言（sdx-feature）

公共质检维见 [受众与语言](../../../references/audience-and-language.md)。

## 主读者

产品、需求分析人员及参与范围评审的业务方；读者须能判断能力、规则、验收和协作责任。

## 宜写 / 宜弱化

| 宜写 | 宜弱化 |
| --- | --- |
| 角色、场景、业务对象、规则、可观察验收 | 类、方法、接口、表字段、中间件 |
| 业务能力域、交付价值、团队与环节依赖 | 工程模块、包、服务名、协议栈 |
| 可感知的非功能承诺 | 未经确认的技术数值与实现方案 |

## 反例

| 避免 | 推荐 |
| --- | --- |
| 调用 OrderService.submit() | 用户提交后进入审核 |
| 更新 order_item 字段 | 保存订单明细并可追溯修改记录 |

## 特殊允许区

§1–§5、§6.1–§6.2 使用业务语言；参考文档的文件名与 ADR ID 可原样保留以便定位。工程线索仅收在 §6.3 的「待研发确认」备注，不冒充变更事实。§3 未确定的量化指标标「与研发共拟」，不擅自承诺。
