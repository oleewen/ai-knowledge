# 受众与语言（sdx-prd）

**产品**主笔与验收对齐；**研发**参评可行性/范围，不以实现说明顶替产品叙述。与 [sdx-solution/audience-and-language](../../sdx-solution/references/audience-and-language.md) 同原则：**角色、能力、旅程、故事与验收、信息架构与交互规则、业务规则与数据语义**写在 PRD；**实现细节** → **ASD/DSD**。

## 宜写 / 宜弱化

| 宜 PRD | 宜弱化（给 ASD/DSD） |
|--------|----------------------|
| 流程、故事、用例、验收 | 类名、接口路径、协议 |
| 信息架构、操作路径、校验反馈 | 表名字段、缓存队列选型 |
| BR-n、数据字典（业务语义） | 框架、中间件、部署拆分 |
| 跨系统业务边界与同步/异步语义 | 调优与实现方案 |

工程线索可放 §11.1 备注或「待研发确认」，勿散在需求正文。
