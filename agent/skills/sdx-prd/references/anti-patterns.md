# sdx-prd 概念反模式

只列会改变处理决策的偏差；推进约束见 [gates.md](gates.md)，操作故障见 [gotchas.md](../gotchas.md)。

| 偏差 | 纠正 |
| --- | --- |
| 把 ANALYSIS 或功能列表当直接上游 | 先取得并对齐 FEATURE 的目标 MVP |
| 只读评审也创建骨架或要求写前 C | 只输出有原文依据的缺口与建议 |
| 局部修订重建全稿、改动未授权章节 | 保留其他内容；跨段影响先报告并确认 |
| 参数齐全便填满十一章 | 参数确定不等于各段业务意图确认；按当前段推进 |
| F 覆盖已确认前文或跳过剩余意图确认 | 按共享批量补齐与重开协议处理 |
| 写前澄清称作 grilling，或每轮烤干都要求 G | 澄清在写前；自动烤干收敛后 G 才表示额外深挖 |
| 需求正文堆接口、DDL、选型 | 改为产品行为；工程线索放 §11.1 备注或交 ASD/DSD |
| 校验退出 0 就勾选全部 §11.3 | 区分无目标、结构通过与语义验收；每项凭证据勾选 |
| 补造 knowledge、指标或 MVP 以填空 | 标明缺口，核实后再写 |
| 恢复旧 HTML gate / CONFIRMED / 会话 spec / 写前 hook | 使用现有段落协议；十一章是结构，不是旧 11G/6G 门禁 |
