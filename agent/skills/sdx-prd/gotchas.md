# sdx-prd 操作层陷阱

按现象定位；业务反模式见 [anti-patterns.md](references/anti-patterns.md)。

| 现象 | 处理 |
| --- | --- |
| 找不到上游 | 核实 FEATURE 实际路径及目标 MVP；ANALYSIS 只能补背景，不自动变成 FEATURE |
| 公司或元库里落错路径 | 读取承接系统/应用的配置与索引，按 [workflow.md](references/workflow.md#定位目标库) 定位 |
| 已有 PRD 被重建 | 先识别新建/修订/评审，读取已有内容后只处理本轮范围 |
| `parent` 仍指 ANALYSIS | 核实同链 FEATURE 后修正；不能只为消除告警伪造关联 |
| 空节很多但脚本返回 0 | 检查实际扫描数与告警；占位或结构通过不表示正文完成 |
| Bash 版本不足或 Python 不可用 | 按 `--help` 补齐依赖；未执行成功不记录为通过 |
| 相对路径找错文件 | `--file` 以调用目录为基准；命令中的脚本路径使用实际安装位置 |
| 元数据格式被拒绝 | 校验器只支持模板 frontmatter 子集；不要把完整 YAML 支持当作既有能力 |
| 中途继续补段 | 沿用已确认参数和当前段状态，读取必要上下文；不重复初始化或改动未选段 |
