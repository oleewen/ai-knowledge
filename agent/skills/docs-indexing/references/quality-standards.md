# 索引验收

在正文完成后、更新完成锚点前检查；写后烤干遵循 [workflow.md](workflow.md)。

## 内容与结构

- [ ] 九章及固定小节齐全；无内容用 `[未索引]` 并说明原因。
- [ ] 事实、版本、接口与路径均有实际读取证据；无法核实的不写成结论。
- [ ] 条目简短、可导航，优先表格；不把指南写成教程或命令手册。
- [ ] 同一事实只在最合适章节定义，跨章用链接；不以“一文件只能一章”掩盖同文件的不同职责。
- [ ] 路径展示与目标仓库约定一致，Markdown 链接从指南位置能正确解析。

## 覆盖与增量

- [ ] 第八章区分脚本候选统计与 Agent 实际阅读，列出未读、部分读取、排除项及原因。
- [ ] depth 3 已遍历确认范围，未用抽样代替精读。
- [ ] incremental 基线有效，四类 Git 变更均已检查；重命名和删除已处理，未变章节仍在。
- [ ] 收尾前复查扫描期间变化；源文件仍有未覆盖变化时保留旧完成锚点。

## 写入边界

- [ ] frontmatter、OKF 与 docs-build 实体块保留；实体块的失效引用单独报告。
- [ ] 只写当前目标指南，没有独立日志或未授权下游产物。
- [ ] 预览及候选扫描不改文件；`--rewrite` 只改运行块。
- [ ] 正文成功后才显式更新唯一正文锚点；代码围栏示例不算锚点。
- [ ] 写后完成 [受众质检](audience-and-language.md) 与当前单元烤干，再等待用户动作。
