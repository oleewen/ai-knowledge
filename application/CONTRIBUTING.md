## 必须遵守

1. **引用优先**：能链权威就不复写。
2. **ID 稳定**：改已有 ID 须同步全链路引用。
3. **仅写 ID**：跨文件/跨视角关联只写 ID，不复制目标正文。
4. **变更可检索**：改文档后更新目标目录 README 索引表；按需同步 INDEX-GUIDE / index。
5. **提交规范**：Conventional Commits；跨目录/规则变更建议补 ADR。

## 最小清单
