# 示例应用解决方案

> **结论**：在本应用内先收敛「申诉提交通道 + 进度可见」，再扩审核协同。  
> 读者：业务与产品。路径：`application/solutions/`。  
> 下游：[../analysis/ANALYSIS-EXAMPLE.md](../analysis/ANALYSIS-EXAMPLE.md)

---

## 1. 背景与目标

### 1.1 业务现状

用户对账单有异议时，经客服或线下渠道发起申诉；进度靠人工转告，业务侧难自助跟踪。

### 1.2 存在问题

入口分散 → 重复提交；进度不可见 → 催单多；口径靠口头 → 争议难收口。

### 1.3 业务目标

| 目标编号 | 目标 | 度量 | 预期收益 |
| -------- | ---- | ---- | -------- |
| G-1 | 本应用内提供唯一申诉提交通道 | 主路径申诉经该通道占比达标 | 少重复单、少入口切换 |
| G-2 | 提交后进度对用户与客服可见 | 催单量下降；自助查进度可用 | 降人工转告成本 |

---

## 2. 范围与约束

### 2.1 核心场景

用户在本应用发起账单申诉 → 填写原因与凭证 → 查看审核进度与结果说明。

### 2.2 涉及角色

| 用户角色 | 角色描述 | 核心关注点 |
| -------- | -------- | ---------- |
| 终端用户 | 发起与跟踪申诉 | 入口清晰、进度可见 |
| 客服 | 协助解释与催办 | 状态一致、少重复问询 |
| 审核人员 | 处理申诉结论 | 材料齐全、口径可依 |

### 2.3 范围边界

#### 范围内（In Scope）

- 本应用内申诉提交、进度展示、结果说明
- 与本应用既有账单查询的衔接（业务话术）

#### 范围外（Out of Scope）

- 跨应用系统编排与统一视图（见 `system/solutions/`、`company/solutions/`）
- 审核规则引擎大改（本轮只对齐展示与提交流程）

#### 成功标准

- 主路径可在本应用完成提交与查进度
- 典型催单场景显著减少（业务可验收口径）

---

## 3. 影响与冲突

### 3.1 影响面

- 用户：少多入口、可自助看进度
- 客服：解释口径与系统状态对齐
- 审核：材料入口更集中

### 3.2 影响业务能力

| 功能/业务能力 | 影响程度 | 影响类型 | 影响说明 |
| ------------ | -------- | -------- | -------- |
| 账单查询 | 中 | 衔接增强 | 从查账进入申诉入口 |
| 申诉提交 | 高 | 流程新建/收敛 | 多入口 → 唯一通道 |
| 进度查询 | 高 | 能力新增 | 自助可见状态 |

### 3.3 影响传播路径

```text
[账单查询] → [申诉提交] → [进度查询] → [客服解释]
```

### 3.4 业务冲突

| 冲突编号 | 冲突描述 | 冲突类型 | 严重程度 | 化解方案 | 化解成本 |
| -------- | -------- | -------- | -------- | -------- | -------- |
| C-1 | 旧线下入口与应用内通道并存导致双单 | 流程冲突 | 中 | 宣布主通道并设过渡期引导 | 中 |

---

## 4. 思路与方案

### 4.1 解决思路

**结论**：先收口提交与进度可见（本应用闭环），再视效果扩展审核协同。取舍见 §5.2。

### 4.2 关键约束

| 约束类型 | 约束描述 | 影响 |
| -------- | -------- | ---- |
| 业务 | 对外解释须与应用内状态一致 | 进度文案须可对客 |
| 资源 | 最小改动；优先主路径账单类型 | 分阶段覆盖账单类型 |
| 技术 | 正文不写实现栈；能力限制用业务话术 | 细节待研发确认 |
| 交付 | 无外部硬截止；每阶段可独立验收 | 节奏由业务优先级驱动 |

---

## 5. 风险与待定

### 5.1 风险评估

| 风险编号 | 风险描述 | 可能性 | 影响程度 | 应对策略 |
| -------- | -------- | ------ | -------- | -------- |
| R-1 | 旧入口未关导致双单 | 中 | 中 | 过渡期双写监测 + 引导关旧 |
| R-2 | 进度文案与审核实态不一致 | 中 | 高 | 状态词典与审核结论对齐 |

### 5.2 问题决策

| 决策编号 | 决策点 | 影响 | 决策要点 | 状态 |
| -------- | ------ | ---- | -------- | ---- |
| Q-1 | 是否本轮就关停全部线下入口 | 双单风险与切换成本 | 推荐：保留过渡期并行，主推应用内；备选：一刀切关旧 | 已决策 |
| Q-2 | 进度状态对外文案最终词典 | 客服解释与争议 | 待业务/客服共定状态词典 | 待确认 |

### 6.1 关键里程碑

| 里程碑 | 覆盖范围 | 前置条件 | 交付物 | 验收标准 | 退出条件 |
| ------ | -------- | -------- | ------ | -------- | -------- |

| 里程碑-2 | 扩账单类型与结果说明完善 | 里程碑-1 退出；Q-2 收敛或有临时词典 | 扩展覆盖 + 结果说明 | 约定类型可走通；催单下降可验收 | 无阻塞性口径缺口 |
